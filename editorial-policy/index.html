Editorial policy

How we choose software, check facts and correct mistakes.

Last updated: 14 November 2026

Which software we list

We list applications for Windows that are free to download and use. We prefer software that is open source, actively maintained, and distributed through an official website or public source repository. We do not list software that is distributed only through third-party download sites.

Sources we rely on

For versions, release dates, download formats and Windows compatibility, we use the project’s official sources only:

  • the project’s own website and download page;
  • the project’s official release page and release notes;
  • documentation published in the project’s official source repository.

Third-party download portals often show outdated or incorrect compatibility information, so we do not treat them as evidence.

How we label information

  • Supported – the official source states support for this Windows version in the current release.
  • Older version only – only an older release supports this Windows version.
  • Runs, not supported – the project says the software runs, but it does not support this Windows version.
  • Reported, not yet verified – a secondary source reports it; we have not confirmed it with the official source.
  • Not confirmed – we have no reliable information.

When we have not verified a version number, release date, file size, checksum or architecture, we leave it out rather than guess. Each listing shows when it was last checked against official sources, or says that some details are awaiting verification.

Download links

Download buttons link to the official download or release page, not to copies of files. We do not present source code archives as ready-to-install software. We encourage readers to verify publishers, release notes and published checksums or signatures before installing anything.

Independence and money

We are not paid to list or rank software. Codehimblog does not currently display advertising or use affiliate links. If this changes, advertising will be clearly separated from download buttons and disclosed in our privacy policy and disclaimer.

Corrections

Software changes quickly. If a listing is out of date or wrong, please tell us through the contact page, ideally with a link to the official source. We review reports and update the listing and its “last checked” date.

C Codehimblog

Codehimblog is an independent directory of free and open-source apps and games for Windows. We describe each application, record which Windows versions its official sources support, and link to official downloads. We do not host or modify software.
