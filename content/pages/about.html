{{site.name}} helps Windows users discover useful free and open-source applications, understand what they do, check which Windows versions they support, and find the official place to download them.

What you will find here

  • Plain-language descriptions of each application and its key features.
  • Windows compatibility notes for Windows 11, 10, 8.1, 8 and 7, based on what each project’s official sources say about the current release.
  • Download format guidance that separates installers (EXE and MSI), portable packages and source code.
  • Links to official sources – the project website, download page, release page and source repository.

What we do not do

  • We do not host, mirror, bundle or modify any software. Download links go to the official project.
  • We do not publish made-up ratings, download counts or popularity figures.
  • We do not mark a Windows version as supported unless the project’s official sources state it.
  • We do not run advertising, analytics or affiliate programmes at this time. If that changes, we will update our privacy policy and disclaimer first.

How listings are checked

Our editorial policy explains how we choose applications, which sources we trust, and how we label information that has not yet been verified. If you spot an error, please contact us.
