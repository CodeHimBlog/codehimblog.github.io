About PATHS

PATHS is a small command‑line utility that lets you view and edit the system PATH and PATHEXT variables. It is useful for users who need to tidy up or modify the list of folders and file extensions that Windows uses to locate executables.

The program can list the current entries, add new ones, delete existing entries, and clean duplicate or empty items. It works with both the user‑level and machine‑level environment settings. When changes are made it notifies Windows so new processes see the updated values without requiring a log‑off. The tool also supports exporting the variables to a registry script while preserving any environment‑variable references such as %SystemRoot%\system32. Errors that require administrator rights are reported with a clear message instead of crashing.

Key features

  • List current PATH and PATHEXT entries
  • Add a new folder or extension to the variables
  • Remove selected entries
  • Clean duplicate or empty entries
  • Export the variables to a .reg file preserving environment references
  • Automatic notification to Windows so changes take effect immediately
  • Shows friendly error messages when admin rights are needed
