About Rubylight

Rubylight lets you stream games from your PC to other devices such as TVs, phones, tablets, laptops or web browsers. It works with Moonlight and other Sunshine‑compatible clients and provides per‑game and per‑device settings.

Rubylight gathers games from all major launchers (Steam, Epic, Battle.net, EA app, Ubisoft Connect, GOG, Xbox, Microsoft Store, Playnite) and presents them with cover art. Each client device receives a virtual display that matches its resolution, refresh rate and HDR capabilities, so the game renders optimally for that screen. The host restores the original monitor configuration after streaming ends or after a crash. Features include moving a running game between devices, dual‑screen mode, browser streaming with H.264/HEVC/AV1, and integration with the Nightjar client for on‑the‑couch control of bitrate and graphics settings.

Key features

  • Streams games from a PC to TVs, phones, tablets, laptops or browsers
  • Supports AMD Radeon and NVIDIA graphics cards
  • Automatically imports libraries from major launchers
  • Creates a virtual display sized for each client device
  • Allows moving a running game between devices or streaming to multiple devices simultaneously
  • Provides per‑game and per‑device encoder and input settings
  • Works with Moonlight, Artemis, Nightjar and other Sunshine‑compatible clients
  • Restores original monitor configuration after streaming stops

Frequently asked questions

Which graphics cards are supported?

Rubylight works with AMD Radeon and NVIDIA GPUs.

Can I stream to a web browser?

Yes, you can stream to browsers that support WebRTC using H.264, HEVC or AV1.

Do I need to install anything on the client device?

No, client devices use Moonlight or compatible apps; Nightjar provides additional features but is not required.

Will my monitor settings be changed permanently?

No, Rubylight restores the original monitor configuration after the stream ends.

Is the software free?

Yes, it is free and open‑source under the GPL‑3.0 license.
