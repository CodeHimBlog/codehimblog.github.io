About IPTVnator

IPTVnator is a cross‑platform IPTV player for Windows. It reads local or remote playlists and provides live TV, video‑on‑demand and a simple interface for managing favorites and watch history.

The program supports M3U and M3U8 playlists, Xtream Codes accounts and Stalker/Ministra portals. It shows channel groups, a searchable guide and allows you to mark favorites. Movies and series are displayed with posters, seasons and resume positions, and you can add TMDB metadata if you have an API key. Playback can use the built‑in player or external players such as MPV or VLC. The app includes a download manager for offline viewing, light and dark themes, keyboard shortcuts and a command palette. A self‑hosted PWA server can be started from the desktop app to share sources with other devices on the same network.

Key features

  • Supports local and remote M3U/M3U8 playlists, Xtream Codes and Stalker portals
  • Live TV with channel groups, search, favorites and programme guide
  • Movies and series with posters, seasons, watch history and resume
  • Built‑in player plus optional external MPV/VLC playback
  • Download manager for offline watching of movies and episodes
  • Light and dark themes with 21 language options
  • Keyboard shortcuts and command palette for quick navigation
  • Self‑hosted PWA server to share libraries across devices

Frequently asked questions

What types of playlists does IPTVnator support?

It works with M3U, M3U8, Xtream Codes and Stalker/Ministra sources.

Can I watch content offline?

Yes, the built‑in download manager lets you save movies and episodes for later viewing.

Does IPTVnator need an internet connection to run?

It needs internet to stream live TV or fetch remote playlists, but local playlists can be used offline.
