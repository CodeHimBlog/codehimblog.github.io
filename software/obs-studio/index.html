About OBS Studio

OBS Studio (Open Broadcaster Software) is used to record video and to stream live to supported platforms. You build scenes from sources such as screen and window capture, webcams, images, browser sources and audio inputs, then switch between them while recording or streaming.

It includes an audio mixer with per-source filters, a studio mode for previewing scenes before they go live, configurable hotkeys and support for third-party plugins. Hardware-accelerated encoding is available on supported graphics cards.

Recording and streaming are demanding tasks, so check the official release notes and your graphics driver version before upgrading.

Key features

  • Scene-based recording and streaming
  • Screen, window, game and webcam capture sources
  • Audio mixer with per-source filters
  • Studio mode to preview scenes before switching
  • Configurable hotkeys
  • Plugin and script support
  • Hardware-accelerated encoding on supported GPUs

How to install OBS Studio

  1. Open the official OBS Studio download page.
  2. Download the Windows installer, or the ZIP package from the official GitHub releases page if you prefer it.
  3. Update your graphics driver before the first launch if you plan to use hardware encoding.
  4. Run the installer and follow the setup steps.
  5. On first launch, use the Auto-Configuration Wizard or set your recording and streaming options manually.
