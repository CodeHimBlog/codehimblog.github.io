About PiPixiv

PiPixiv provides a native Windows interface for exploring Pixiv. You can log in with your Pixiv account, browse the home feed, rankings, and search results, read novels, and download artwork directly to your computer.

The program is built with Compose Multiplatform and runs on 64‑bit Windows. It supports Pixiv authentication via OAuth or by reusing a web‑session cookie, so you do not need to enter a token manually. The home screen shows a waterfall feed of recommended illustrations, and you can switch to view the latest updates, your favorites, or followed users. Rankings are available for daily, weekly, monthly, and various categories such as male‑oriented, female‑oriented, and AI‑generated works.

Illustrations can be opened in detail, with options to select image quality, zoom, and view related works. You can download original images or GIFs, customize file names, and manage a download queue. The novel viewer offers immersive reading with adjustable font size, line spacing, and scroll position memory. Novel pages can be translated using OpenAI, Claude, Gemini or compatible services, with options for local caching and streaming of translations.

Search lets you find illustrations, novels, or users, sort by popularity or recency, and apply filters. Tags can be long‑pressed to bookmark or copy. User profiles display author information, works, and public collections. The app also remembers your preferences for sorting and filtering between sessions.

When the program starts on Windows, it checks for the WebView2 runtime. If the runtime is missing and a web login fails, it offers a recovery option to install WebView2.

Key features

  • Log in with Pixiv account via OAuth or reuse browser cookies
  • Browse home feed, latest updates, and multiple ranking lists
  • View illustration details, zoom, select quality, and download originals
  • Read novels with adjustable font settings and automatic progress saving
  • Translate novel text using AI services with local caching
  • Search illustrations, novels, and users with sorting and filtering options
  • Bookmark tags, copy them, and view author profiles
  • Manage download queue and customize file naming

Frequently asked questions

Is PiPixiv free to use?

Yes, the application is free and open source.

Is it safe to log in with my Pixiv account?

The app uses official OAuth authentication and can also use your existing browser session cookie, so your credentials are handled securely.

How do I get updates?

Updates are released on the project's GitHub page; the installer will replace the previous version.

How can I uninstall PiPixiv?

Remove it through Windows' standard "Add or remove programs" settings.

Do I need an internet connection?

Yes, the app requires internet access to load Pixiv content and perform translations.
