About DYGTube

DYGTube is a free program that lets you save audio (MP3) and video (MP4) files from websites to your computer. It provides a graphical interface that is easy to use for anyone who wants to keep a copy of online media for offline viewing or listening.

The application runs on Windows and offers a friendly, intuitive window where you can paste a video URL, choose the format (MP3 or MP4), and start the download. It handles the conversion and saving process automatically, so you do not need separate tools. The project is open source under GPL‑2.0 and is free to use.

Key features

  • Paste a video link and download the audio as MP3.
  • Paste a video link and download the video as MP4.
  • Simple graphical interface with clear buttons.
  • Shows download progress and file size.
  • Saves files to a default folder you can change.
  • Works without needing to install additional codecs.
  • Free and open‑source software.
