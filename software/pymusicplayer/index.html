About PyMusicPlayer

PyMusicPlayer is a desktop music player for Windows built with wxPython and the BASS audio library. It plays a wide range of audio files, streams internet radio, and provides detailed audio analysis such as tempo, key, and loudness. The player shows waveforms as a seek bar and offers tools for editing tags and cover images.

The player supports common formats like MP3, WAV, OGG, FLAC, AAC, and more, using optional BASS add‑ons for additional codecs. Users can drag files, folders, or playlists onto the interface, and the program will analyze each track in the background, storing results in an SQLite cache. Analysis includes tempo, musical key, loudness, highlights, and beat grids, which can be used for smart playback modes such as playing only the highlight or a short edit of each song.

Waveforms are displayed both as the main seek bar and as a zoomed view that follows playback, allowing precise scrubbing. The interface includes a sidebar with sections for playlists, library, radio stations, and folders, plus searchable and filterable lists. Tag editing and cover image tools let users modify metadata, fetch information from online services, and edit images directly.

Additional features include pitch and tempo control, automatic mastering with VST support, various audio meters and visualizers, customizable keyboard shortcuts, always‑on‑top mode, and the ability to register the player as the default handler for audio file types.

Key features

  • Plays many audio formats including MP3, WAV, OGG, FLAC, AAC and more
  • Streams internet radio via HTTP, HTTPS and HLS
  • Shows full‑song waveform as seek bar with zoomed view for precise scrubbing
  • Analyzes tracks in background for tempo, key, loudness, highlights and beat grid
  • Stores analysis in SQLite cache to avoid re‑analysis of unchanged files
  • Playback modes: highlight only, short edit, loop, skip silence
  • Pitch and tempo control with optional key lock
  • Automatic mastering with VST plugin and visual meters
  • Tag and cover image editor with online lookup from Discogs and Last.fm
  • Customizable keyboard shortcuts and always‑on‑top option

How to install PyMusicPlayer

  1. Download PyMusicPlayer-Setup.exe from the official GitHub release page.
  2. Run the installer and follow the on‑screen prompts.
  3. After installation, launch PyMusicPlayer from the Start menu or desktop shortcut.
  4. (Optional) Register the player as the default program for audio files in Windows Settings.
  5. Open music files or drag them onto the player to start listening.

Frequently asked questions

Which audio formats are supported?

MP3, MP2, WAV, OGG, AIFF, M4A, MP4, AAC, FLAC, APE, WMA, AC3 and others via optional BASS add‑ons.

Can I stream internet radio?

Yes, the player can play radio streams over HTTP, HTTPS and HLS and includes a station browser.

Does the player analyze my music automatically?

Yes, it runs background analysis for tempo, key, loudness and more, storing results for future use.

How do I edit tags and cover art?

Use the built‑in track editor to modify ID3 tags, fetch information online, and edit or replace cover images.

Is the software free?

Yes, it is open‑source and released under the MIT license.
