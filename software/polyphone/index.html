About Polyphone

Polyphone is a soundfont editor that lets you design musical instruments from recordings, modify existing soundfonts, and play them with a built-in synthesizer. It runs on Windows and offers both an installer and a portable version.

Polyphone works with standard soundfont formats (sf2, sf3) and can import/export other instrument formats such as sfz, DLS, and sfArk. You can import audio samples in wav, flac, ogg, mp3, aiff and snd formats, edit them with a waveform view, set loop points, and apply pitch analysis. The program includes graphical editors for key and velocity ranges, envelopes, and modulators, plus a table view for bulk editing. Over 30 automation tools help with tasks like automatic looping, sample positioning, chord creation, and batch processing. A built-in synthesizer with reverb and chorus can be played via virtual keyboard, MIDI keyboard, or computer keyboard, and you can also play MIDI files, record to wav, and output audio through system, JACK, or ASIO. An integrated soundfont explorer lets you browse, filter, and preview soundfonts locally or from an online repository. The interface is translated into 16 languages and supports light, dark, or custom themes.

Key features

  • Open and save sf2 and sf3 soundfonts, import/export sfz, DLS, sfArk, and GrandOrgue organs
  • Import audio samples (wav, flac, ogg, mp3, aiff, snd) and export as wav
  • Sample editor with waveform view, loop points, pitch analysis and equalizer
  • Graphical editors for key/velocity ranges, envelopes and modulators
  • Over 30 automation tools for looping, positioning, chord creation and batch processing
  • Built-in synthesizer with reverb, chorus, MIDI and computer keyboard support
  • MIDI file player with channel control and wav export
  • Soundfont explorer for browsing and previewing local and online soundfonts
  • Command‑line utilities for conversion and rendering
  • Interface available in 16 languages with light, dark and custom themes

Frequently asked questions

What file formats can Polyphone open?

It supports sf2, sf3, sfz, DLS, sfArk, GrandOrgue organs and audio samples like wav, flac, ogg, mp3, aiff and snd.

Do I need to install anything extra to use the synthesizer?

No, the built‑in synthesizer works out of the box, with optional output via system, JACK or ASIO.

Is there a portable version?

Yes, a portable ZIP is provided that runs without installation.

Can I use Polyphone to convert soundfonts to other formats?

Yes, it includes tools for converting between sf2, sf3, sfz, DLS and exporting parameters to CSV.

Is Polyphone free?

Yes, it is free and open‑source under the GPL‑3.0 license.
