About Readest

Readest provides a modern interface for reading digital books on Windows. It supports a wide range of formats, offers library organization, and includes tools such as highlighting, dictionary lookup, and text‑to‑speech.

Readest is an open‑source ebook reader built with modern web technologies. It runs on Windows and can open EPUB, PDF, MOBI, AZW3, FB2, CBZ, TXT, HTML and Markdown files. Users can switch between scrolling and paginated views, search within a book or across the library, and add highlights, bookmarks and notes. The program includes built‑in dictionary and Wikipedia lookup, and lets you import custom dictionaries. A split‑screen mode allows reading two documents side by side. Font, theme, and layout settings are fully customizable. Library management features let you sort and organize your collection, and integration with OPDS/Calibre gives access to online catalogs. Additional tools include web page clipping, instant translation via DeepL or Yandex, audiobook playback, and multilingual text‑to‑speech narration.

Key features

  • Open many ebook formats including EPUB, PDF, MOBI and more
  • Switch between scrolling and page‑by‑page reading modes
  • Search inside books or across the whole library
  • Highlight text, add bookmarks and write notes
  • Look up words with built‑in dictionary or custom packs
  • Split‑screen view to read two documents at once
  • Adjust fonts, themes and layout to suit your preference
  • Play audiobooks and use text‑to‑speech narration

Frequently asked questions

Is Readest free to use?

Yes, it is completely free and open source.

Is it safe to install on my computer?

The program is released under the AGPL‑3.0 license and contains no hidden malware.

How do I get updates?

New versions are provided as Windows installers; replace the old files with the new installer.

How can I uninstall Readest?

Use Windows' standard Add or Remove Programs feature.
