About OpenAgentd

OpenAgentd lets you give a folder and a task to a local coding agent. The agent plans, edits code, runs tests and displays each step in a clear transcript. You can review changes before they are applied and use the AI models and API keys you already have.

The app runs a native backend written in Rust and provides a graphical interface where you can see tool calls, arguments, timings, diffs and costs. It works with real Git repositories, showing history, worktrees and diagnostics. You choose a model provider—such as OpenAI, Anthropic, Gemini, or a local Ollama model—by entering an API key or signing in. The agent asks for secrets only when needed and never stores them elsewhere. Sessions, settings and any telemetry stay on your computer. You can also connect from iPhone or Android apps to answer questions or approve plans remotely. Extensions and plugins allow adding new skills, image or video generation, and chaining multiple tool calls.

Key features

  • Shows every tool call, command output and file edit in real time
  • Displays Git diffs and lets you approve or reject changes before they are committed
  • Supports many AI model providers and lets you use your own API keys or local models
  • Works with existing Git repositories, including history, worktrees and diagnostics
  • Provides a companion mobile app to monitor and interact with sessions remotely
  • Extensible via plugins and skills for additional functionality

How to install OpenAgentd

  1. Click the "Download OpenAgentd" button on this page. Your browser saves openagentd-3.59.0-x86_64-pc-windows-msvc.zip (24.6 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the OpenAgentd program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.
  4. When OpenAgentd starts, the first screen asks you to connect a model: paste an API key, sign in with a subscription, or select a local Ollama model.
  5. After connecting a model, open a folder and describe the task you want the agent to perform.

Frequently asked questions

Is OpenAgentd free?

Yes, it is open‑source and free to use.

Is it safe to run on my computer?

The application runs locally and does not send your code or data to external servers unless you provide API keys for a model.

How do I get updates?

Download the latest Windows ZIP from the official release page and replace the existing files.

How can I uninstall it?

Delete the program folder; no additional components are installed.

Do I need an internet connection?

Only if you use a cloud model that requires API access; local models work offline.
