About keep-sorted

keep-sorted is a small command‑line utility that automatically orders lines of code or data that are enclosed by special marker comments. It works with many programming languages and file types without needing language‑specific knowledge.

The tool looks for comment markers such as // keep-sorted start and // keep-sorted end (or similar markers in other languages). All lines between the markers are treated as a block and are sorted alphabetically. This helps keep import lists, module declarations, array initializers, and other ordered sections tidy and consistent. keep-sorted can handle simple line continuations, more complex blocks with balanced symbols, and custom prefix grouping. It can be run directly on files or used in a pre‑commit hook to enforce sorting automatically.

Key features

  • Sorts lines between start and end markers in many programming languages.
  • Supports simple line continuations based on indentation.
  • Handles complex blocks with balanced braces, brackets, parentheses, and quotes.
  • Allows custom prefix groups to define continuation lines.
  • Can be used in pre‑commit hooks for automatic sorting on each commit.
  • Provides a lint mode to check files without modifying them.
  • Works as a standalone Windows executable.
