About FrostWire

FrostWire lets you search for files on the internet, download them directly or via BitTorrent, and share files with other users. It includes a built‑in search engine, a simple library for managing your downloads, and a lightweight mode for slower computers.

FrostWire is a cross‑platform desktop client that provides a single interface for downloading files from HTTP/HTTPS sources and the BitTorrent network. The program bundles its own Java runtime, so you do not need to install Java separately. It also supports WebTorrent, allowing connections to peers in web browsers. A Lite mode reduces resource usage on older machines. The software is released under the GPL‑3.0 license and is free to use.

Key features

  • Search for files across multiple sources from within the app
  • Download files via direct links or BitTorrent
  • Share downloaded files with other FrostWire users
  • Connect to WebTorrent peers in web browsers
  • Lite mode for lower‑end computers
  • Built‑in library to organize and play media files
  • Automatic updates of the bundled Java runtime for security
