About WooHaa3

WooHaa3 provides a unified canvas where you can organize different media types, generate new content with AI models, edit and iterate on results, and work with 3D scenes and camera angles without leaving the application.

The program lets you place text, pictures, sound, video and 3D models together on one canvas. You can connect to local AI agents or external model services, choose a model, write a prompt and generate new images, videos or 3D assets based on existing material. Generated results can be edited further, annotated, or used as references for additional AI runs. A built‑in 3D director lets you create scenes, adjust camera positions and export those views as references for image generation. Plugins allow you to add custom model services, and a Photoshop‑like editor is available for detailed image retouching. All work is stored locally, so you can use the tool without an internet connection unless you need external AI services.

Key features

  • Organize text, images, audio, video and 3D models on a single canvas
  • Generate new media using AI models with custom prompts
  • Edit images and videos directly within the app, including Photoshop‑like retouching
  • Create and adjust 3D scenes, set camera angles and use them as generation references
  • Connect to local AI agents or configure external model services via API keys
  • Extend functionality with a plugin system for additional models and services

How to install WooHaa3

  1. Click the "Download WooHaa3" button on this page. Your browser saves WooHaa3_0.1.26_x64-setup.exe (170.5 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start WooHaa3 from the Start menu or the desktop shortcut.
  4. On first launch, open the AI Capability Center to connect a local agent or enter an API key for a model service
  5. Enable desired models in the plugin details panel before generating content
