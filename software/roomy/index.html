About Roomy

Roomy helps you find files and folders that take up space on your computer. It explains each item, tells you if it is safe to delete, and lets you remove unwanted data with a single click.

Roomy looks for common space hogs such as Windows Update leftovers, temporary files, app caches, browser caches, GPU shader caches, old installers, large downloads, unused Steam games, Windows.old folders, leftover AppData folders and the hidden hibernation file. It presents the results in a clear list and a visual space map that lets you explore folders to see the biggest files. You can run scans manually or let Roomy check your system drive periodically in the background. Alerts and reminders are optional and can be configured for frequency and size thresholds. Settings are stored locally and the program can stay running in the system tray, start with Windows, or be closed completely. All operations are performed offline and the software is open source and free.

Key features

  • Scans drives and shows space‑consuming items in plain English
  • Explains why each item exists and whether it is safe to delete
  • One‑click cleaning of safe files and folders
  • Visual space map for browsing large files folder by folder
  • Optional background checks and low‑space alerts
  • System‑tray icon for quick access and to keep Roomy running
  • Can start automatically with Windows
  • Handles hibernation file and can disable/enable hibernation

How to install Roomy

  1. Click the "Download Roomy" button on this page. Your browser saves Roomy-Setup.exe (68.0 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start Roomy from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. Use the tray menu to keep Roomy running, scan, pause reminders or quit
  6. Enable "Start with Windows" to launch quietly in the tray at sign‑in

Frequently asked questions

Is Roomy free?

Yes, it is free and open source.

How does it update?

How do I uninstall?
