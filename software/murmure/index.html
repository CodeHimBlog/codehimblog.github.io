About Murmure

Murmure lets you dictate spoken words and see them appear as text instantly. All processing is done locally, so no internet connection or data collection is required. It is useful for writing notes, creating prompts for AI tools, or capturing ideas hands‑free.

Murmure is an open‑source transcription tool that uses NVIDIA’s Parakeet neural network model to convert speech to text on the user's machine. The application focuses on privacy: no telemetry, no cloud services, and all data stays on the device. It supports a wide range of European languages, making it suitable for multilingual users. The interface is simple – start recording and the transcribed text appears in real time. Because the computation is local, the program works without any network connection. It can be used to dictate into any text field, generate prompts for AI assistants, or keep a hands‑free notes journal. The software is distributed under the AGPL‑3.0 license and is free to use and modify.

Key features

  • Transcribes speech to text instantly on the computer
  • Works completely offline, no internet needed

  • Supports 25 different languages
  • Uses a neural network model for accurate transcription
  • Simple interface: press record and see text appear

Frequently asked questions

Is Murmure free to use?

Yes, it is free and open source.

Does Murmure send any of my voice data online?

No, all processing happens locally and no data leaves your computer.

How do I update Murmure?

Updates are provided through the standard Windows installer or via winget.

What do I need to run Murmure?

You need Windows 10 or later and the Microsoft Visual C++ Redistributable.
