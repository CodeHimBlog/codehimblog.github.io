About Pylon Player

Pylon Player is a free, open‑source media player for Windows that uses VLC’s playback engine. It provides a simplified, hover‑only control layout, a music library, subtitle timeline editing, per‑show presets, themes and automatic updates.

Pylon Player replaces VLC’s default interface with a quieter set of controls that appear only when needed. Because it runs on libVLC, it can play any format that VLC supports, including video, audio, subtitles and network streams. The player adds features such as a music library with playlists, a side panel that slides in for library and settings, visualizations for audio, the ability to skip silence in tracks, and a "Super Resolution" mode that keeps black bars when videos do not match the screen size. Users can customize shortcuts, choose visual themes, and use picture‑in‑picture mode that stays on top of other windows. The application checks for updates automatically and restores settings from a backup if the configuration file becomes damaged.

Key features

  • Plays all video and audio formats supported by VLC
  • Hover‑only controls keep the screen uncluttered
  • Music library with playlists and shuffle options
  • Subtitle timing view with drag‑to‑sync timeline
  • Visualizations for audio playback
  • Super Resolution mode preserves aspect‑ratio black bars
  • Side panels for library, settings and queue that slide in/out
  • Automatic update checks and settings backup

Frequently asked questions

Is Pylon Player free?

Yes, it is free and open source.

Is it safe to install?

The program is released under the MIT license and does not require additional software beyond VLC, which it can use if already installed.

How do I get updates?

Pylon checks for updates automatically and will prompt you when a new version is available.

How do I uninstall it?

Remove it like any other Windows program through the Add or Remove Programs control panel.

Do I need an internet connection to use it?

An internet connection is only needed for updates or streaming online media; local files play offline.
