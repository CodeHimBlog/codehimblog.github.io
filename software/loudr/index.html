About Loudr

Loudr lets you listen to any text on your screen and dictate into any application without sending data online. It works entirely offline except for optional studio‑voice services.

Loudr is a free, open‑source program that runs on Windows. You can select text in any window and press a hotkey to have it spoken aloud using built‑in voices. By holding a different hotkey you can speak and have your words transcribed directly into the active application. The speech and transcription models are downloaded once and then run locally, so no text leaves your computer. Optional integration with online services such as ElevenLabs or Google Gemini lets you use high‑quality studio voices for saved audio files, but this feature is disabled until you provide your own API key. The program includes a tray icon for quick access to settings, voice selection, and quit options.

Key features

  • Read selected text aloud with a single hotkey
  • Dictate by holding a hotkey and have speech converted to typed text in any app
  • Save spoken scripts as MP3 or WAV files
  • Choose from multiple offline voices, including English and Hindi
  • Optional studio‑voice support for higher‑quality audio using your own API key
  • Simple tray menu for settings, voice selection and quitting the app

Frequently asked questions

Is Loudr free?

Yes, it is free and open‑source.

Does Loudr send my data online?

No, all speech processing is done locally. Only optional studio‑voice services send the audio you choose to save.

How do I update Loudr?

Download the latest installer from the official website and run it; the installer will replace the existing version.

How can I uninstall Loudr?

Use Windows' Add or Remove Programs feature to uninstall Loudr.

Do I need an internet connection?

Only for the one‑time model download and if you enable optional studio‑voice services.
