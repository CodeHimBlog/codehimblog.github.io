About PhotoCraft

PhotoCraft offers a native Windows photo editing experience with familiar menus, shortcuts and panels for users of Photoshop. It runs without web runtimes and uses the GPU for fast performance.

PhotoCraft is a clean‑room reimplementation of Adobe Photoshop built entirely in Rust. It supports layers, masks, adjustment layers, layer styles, text, vectors, brushes and can open, edit and save real Photoshop PSD files. The interface follows the layout and shortcuts that Photoshop users expect, making the transition easy. Under the hood it uses a GPU compositor via wgpu (Metal, Vulkan, DX12, WebGPU) and multithreaded filters for responsive editing. Every UI action is also exposed as a command, allowing control through the CLI, JSON channels or external agents. The project is free, open source and licensed under Apache‑2.0.

Key features

  • Familiar Photoshop‑like menus, shortcuts and panels
  • GPU‑accelerated compositing with wgpu
  • Copy‑on‑write tiles and multithreaded filters for speed
  • Full support for opening and saving layered PSD files
  • Layers, masks, adjustment layers, layer styles, text and vectors
  • Brush engine with customizable brushes
  • Agent‑ready: actions can be driven via CLI, JSON or external servers
  • Runs as a native Windows application, no Electron or web view
