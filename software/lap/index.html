About Lap

Lap is a free, open‑source desktop photo manager that works locally on your computer. It lets you browse, organize and search large personal photo collections without uploading anything to the cloud.

Lap focuses on privacy and performance. Your pictures stay on your own disk and the program works directly with the folders you already use. It provides a folder‑first workflow, so you can import, export, move, copy or delete files while keeping the original structure. The built‑in AI tools run locally and can search by text, visual similarity, faces or tags in many languages. Lap is designed to handle libraries with hundreds of thousands of images, offering smooth browsing, smart albums, duplicate cleanup, culling tools and a four‑pane comparison viewer. The software is released under the GPL‑3.0 license, meaning you can use, modify and share it freely.

Key features

  • Browse libraries by date, folder, location, camera, lens, tags, ratings and faces
  • Folder‑first workflow with drag‑and‑drop, copy‑paste and filesystem sync
  • Local AI search for text prompts, visual similarity, face clustering and multilingual tags
  • Smart Albums that save rule‑based views with custom grouping and sorting
  • Import with automatic date‑based folder organization and duplicate skipping
  • Collections and tags for bulk organization without moving files
  • Duplicate cleanup with space‑reclaim summaries and bulk removal
  • Culling and four‑pane image comparison tools
  • Photo collage creation with multiple layout options

Frequently asked questions

Does Lap store any of my photos in the cloud?

No, all photos remain on your local disk and are never uploaded.

Can I use Lap with an existing folder structure?

Yes, Lap works directly with your existing folders without importing into a separate database.

Is there a portable version?

The official releases are MSI installers; a portable ZIP is not provided.

Which languages does the AI search support?

It can handle text queries in more than 50 languages.

How can I remove duplicate photos?

Use the duplicate cleanup feature to scan for duplicates and delete selected copies.
