About LucidDesk

LucidDesk helps you keep your Windows desktop tidy by grouping icons into customizable panels. You can add folder panels to browse frequently used directories, search the whole system, and preview files without leaving the desktop. The program works with an optional command‑line interface and external agents for automation.

LucidDesk provides a panel‑based workspace on the desktop. Each panel can hold shortcuts, files, or a view of a folder. Panels can be moved, resized, and arranged automatically or manually. You can switch between icon and list views, change themes, and set panels to collapse, lock, or stay on top. The built‑in search integrates with the Everything utility, and pressing space on a selected file shows a preview if PowerToys Peek or QuickLook is installed. Settings and layout can be backed up and restored, and a CLI with JSON output allows scripts or agents to manage panels and backups. The program does not move original files; removing icons from a panel returns them to the desktop.

Key features

  • Organize desktop icons into movable and resizable panels
  • Create folder panels that browse and refresh real directories
  • Integrate with Everything for fast file search
  • Preview files with Space using PowerToys Peek or QuickLook
  • Customize themes, fonts, corner radius, and panel behavior
  • Backup and restore layout and settings
  • Command‑line interface for scripting and agent automation
  • Automatic or manual backup options
  • Support for multiple languages and high‑DPI displays

Frequently asked questions

Do the panels move my original files?

No, icons placed in panels remain in their original locations; removing them from a panel returns them to the desktop.

Is a separate installation required for the search and preview features?

Yes, you need to install Everything for search and PowerToys Peek or QuickLook for preview; LucidDesk does not bundle them.

How can I back up my layout?

Use the Backup & Restore section in Settings to create a backup file, which can later be imported to restore your panels.

Can I run LucidDesk without installing it?

Yes, extract the portable ZIP and run luciddesk.exe; the portable version keeps its configuration in a data folder beside the executable.

Is there a command‑line way to manage panels?

Yes, the included luciddesk-cli.exe provides JSON commands for listing, creating, and modifying panels and backups.
