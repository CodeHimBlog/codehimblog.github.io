About IME Mode Persistence

IME Mode Persistence runs in the system tray and keeps your chosen input mode across applications. It also lets you bind a particular program to always use a specific language, useful for games and other software that bypass normal Windows input settings.

The tool solves a common annoyance where Windows resets the IME conversion mode (Chinese or English) each time you change windows. By remembering the last mode you selected, it ensures the same mode follows you as you work in different programs. It also provides a way to fix the input language for programs that do not respect Windows' normal IME handling, such as fullscreen games that read raw keyboard input. The utility works with Microsoft Bopomofo and shows a small indicator next to the text cursor showing the current mode. It can be installed via the Microsoft Store for automatic updates or used as a portable zip. The program adds an "About..." entry to its tray menu with links to the website, documentation, issue tracker, and source code.

Key features

  • Remembers the last chosen IME conversion mode when you switch windows
  • Allows you to pin a specific program to always use a chosen input language
  • Works with fullscreen games that use raw keyboard input
  • Shows a small cursor‑side indicator displaying the current mode (中 / A)
  • Runs quietly in the system tray with a right‑click menu
  • Portable zip version available, no installation required
