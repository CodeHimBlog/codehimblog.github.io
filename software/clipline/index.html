About ClipLine

ClipLine collects everything you copy – text, links, colors, images, and files – and displays each item as a card on a virtual rope that slides down from the top edge of the screen. A second rope holds sticky notes that support Markdown and checklists. The interface hides when the mouse moves away, keeping your workspace clean while giving quick access to recent clipboard history and notes.

The clipboard rope automatically gathers copied content without creating duplicate cards. Single‑click copies an item, double‑click edits or opens it, and right‑click shows more actions. Cards can be dragged into other applications, saved as text or markdown files, or moved to the desktop as floating windows. Files dragged from Explorer onto the top edge are captured, and the app can monitor a folder to add new files automatically.

Cards are organized into sections: a pinned “Favorites” area, today’s items, and older items grouped by three‑day, one‑week, and older folds. Links can have short remarks for easy identification, and a special feature turns copied group‑chat messages into to‑do items with reminders.

The built‑in screenshot tool (Ctrl+Alt+S) lets you capture, annotate, run OCR, or pin the image directly to the rope. Annotation tools include brush, arrow, rectangle, ellipse, text, mosaic and numbering. OCR uses the Windows built‑in engine, works offline and requires no extra download.

Sticky notes appear on a second rope. The first line is the title; the body supports Markdown formatting and checklists that can be ticked directly on the card. Seven background colors are available, and reminders can be set to repeat daily, weekly or monthly, showing a pop‑up at the scheduled time.

The app offers five visual themes, customizable accent colors, adjustable fonts and sizes, multi‑monitor support, custom hotkeys, start‑up on login, and language choice (Chinese, English or system default). Updates are checked automatically from the GitHub releases page; you can be notified, download automatically, or disable the feature. All data is stored locally in %APPDATA%\com.clipline.app.

Key features

  • Automatically saves copied text, links, colors, images and files as separate cards
  • Click to copy, double‑click to edit or open, right‑click for more actions
  • Drag cards to other apps, save as .txt/.md, or pin as floating windows on the desktop
  • Screenshot tool with annotation options and offline OCR
  • Sticky notes with Markdown support, checklists and repeatable reminders
  • Organises items into favorites, today, and older groups with automatic folding
  • Customizable themes, colors, fonts and hotkeys; works on multiple monitors
  • Automatic update checking and one‑click upgrade

How to install ClipLine

  1. Click the "Download ClipLine" button on this page. Your browser saves ClipLine_1.13.1_x64-setup.exe (1.9 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start ClipLine from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. After the first launch the program checks for updates automatically and can install the latest version without leaving the app.

Frequently asked questions

Is ClipLine free to use?

Yes, it is free.

Does ClipLine send any data online?

No, all data stays on your computer.

How do I update ClipLine?

The app checks for updates automatically and can download and install them with one click.

How can I remove ClipLine?

Use the standard Windows Add or Remove Programs feature for the installed version, or simply delete the portable executable.

Do I need an internet connection to use the core features?

No, clipboard, notes and OCR work offline; an internet connection is only needed for update checks.
