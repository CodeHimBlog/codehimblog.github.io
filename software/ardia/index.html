About Ardia

Ardia provides a Chromium browsing experience without Google services. It places the address bar in a sidebar, lets you split windows into multiple panes, and includes privacy features like built‑in ad blocking and optional crash‑reporting. Profiles keep separate data and sync through iCloud Drive.

Ardia is built on Chromium 158 and removes Google background services, offering a cleaner, faster browser. The sidebar can hold pinned sites, and you can drag tabs to create up to three side‑by‑side or stacked panes. A picture‑in‑picture mode keeps videos playing when you switch tabs. Extensions from the Chrome Web Store work normally, and the browser includes a full uBlock Origin filter list with cookie‑banner handling. Profiles store bookmarks, history, passwords and can import data from other browsers. Themes let you set gradient colours per profile. Sync is end‑to‑end encrypted via your iCloud Drive, with no external servers. Background tabs beyond the five most recent are frozen to save resources, and the browser stays idle at very low CPU usage. Updates are applied silently and then shown to the user.

Key features

  • Moves the address bar into a sidebar for more screen space
  • Split‑view lets you display up to three pages side by side or stacked
  • Built‑in uBlock Origin blocks ads, trackers and cleans copied links
  • Supports Chrome Web Store extensions with a simple “Add to Ardia” button
  • Profiles keep separate bookmarks, history, passwords and can sync via iCloud Drive
  • Picture‑in‑picture keeps videos playing while you browse other tabs
  • Low CPU usage by freezing inactive background tabs

Frequently asked questions

Is Ardia free?

Yes, it is free and open source.

Is it safe to use?

The browser is built from Chromium source and does not send data to external servers; sync is encrypted through your iCloud Drive.

How do I get updates?

Ardia updates itself automatically and notifies you of changes after each update.

How can I uninstall Ardia?

Remove the program folder from your system like any other portable application.

Does Ardia need an internet connection?

An internet connection is required for browsing, but the browser can be installed and run offline.
