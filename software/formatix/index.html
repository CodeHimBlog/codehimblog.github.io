About Formatix Image Converter

Formatix Image Converter lets you convert, resize, and optimise large numbers of images without an internet connection. It runs as a single portable executable, so you can use it on any Windows computer without installation.

The program supports input formats such as AVIF, WEBP, JPEG, PNG, BMP, TIFF, ICO, HEIF/HEIC, and SVG. You can export to eight output formats, adjust compression quality, set target file sizes, and apply smart cropping. The interface includes dark and light themes, drag‑and‑drop, and multilingual support. All processing happens locally, with no ads or telemetry, and the tool can generate Windows icon packs and compare original and processed images side by side.

Key features

  • Batch conversion, resizing and optimisation of hundreds of images at once
  • Supports 8 output formats including AVIF, WEBP, JPEG, HEIC/HEIF, PNG, BMP, TIFF, ICO
  • Multi‑threaded processing for fast performance
  • Five resize modes with smart crop and proportional scaling
  • Adjustable quality settings and target file size option
  • Drag & drop file/folder addition
  • Automatic cache to skip already processed files
  • Light and dark UI themes with multilingual interface
  • Portable single‑exe, no installation required
