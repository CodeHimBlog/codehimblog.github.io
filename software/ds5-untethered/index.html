About DS5 Untethered

DS5 Untethered lets you use a DualSense controller wirelessly while still getting the full range of haptic effects and adaptive trigger feedback that games normally provide only when the controller is connected by USB. It works by pairing the controller via Bluetooth, installing two helper drivers, and presenting a virtual wired DualSense to the game.

The program connects to the DualSense over Bluetooth and runs a local USB/IP server that creates a virtual wired controller. Games communicate with this virtual device as if it were physically plugged in, receiving the controller's haptics, trigger resistance, light bar and audio feedback. Input from the real controller is forwarded to the virtual one, and the output is sent back to the controller over Bluetooth. Two drivers are required: usbip-win2 provides the USB/IP functionality, and HidHide hides the real controller from games so they only see the virtual device. Profiles let you store different haptic and trigger settings for each game and switch between them easily.

Key features

  • Sends full haptic feedback and adaptive trigger effects to a DualSense over Bluetooth
  • Creates a virtual wired controller so games think the controller is plugged in
  • Stores per‑game profiles for haptic, trigger and rumble settings
  • Guides you through driver installation and Bluetooth pairing
  • Works with any game that supports DualSense features on PC
