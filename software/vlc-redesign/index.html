About VLC Media Player Redesign

VLC Media Player Redesign provides the same playback capabilities as the official VLC player while offering a completely new visual layout. It is aimed at users who like VLC’s functionality but want a fresh, modern look. The program works on Windows and other platforms, but this listing covers the Windows version.

The project uses the official VLC 4 core, so all supported video and audio formats, streaming protocols, and subtitle handling remain unchanged. The only difference is the user interface, which has been rebuilt screen by screen according to a design created by the YouTube creator Juxtopposed. The software is free, open‑source and not affiliated with VideoLAN. Installers are provided for both x64 and ARM64 Windows systems, and portable ZIP archives are also available for users who prefer not to run an installer.

Key features

  • Uses the official VLC 4 engine and codecs
  • Completely redesigned user interface
  • Supports all formats that VLC 4 supports
  • Available as installer or portable ZIP for x64 and ARM64
  • Multilingual support (72 languages)
  • Open source under GPL‑2.0
  • No additional codecs required
  • Works with existing VLC playlists and settings

How to install VLC Media Player Redesign

  1. Go to the official GitHub release page.
  2. Download the installer (EXE) for your system architecture (x64 or ARM64) or the portable ZIP.
  3. Run the installer and follow the prompts, or extract the ZIP to a folder.
  4. Launch VLC Media Player Redesign from the Start menu or the extracted folder.
  5. Optionally import existing VLC playlists or settings.

Frequently asked questions

Does this replace my existing VLC installation?

It installs as a separate program, so your original VLC remains unchanged.

Can I use my existing VLC playlists?

Yes, you can open or import playlists created with the standard VLC player.

Is the portable version fully functional?

The portable ZIP contains the same features as the installer version and runs without installation.

Will updates be automatic?

Updates are not automatic; you need to download new releases from the GitHub page.

Is this safe to use?

The program uses the official VLC engine, and the source code is publicly available under an open‑source license.
