About Win.apk

Win.apk lets you install and use Android applications (.apk, .apkm, .xapk, .apks) directly on Windows. Each app appears as its own resizable window, with a Start menu shortcut, taskbar icon, and Windows notifications, giving a native feel while using your PC’s hardware.

Win.apk creates a lightweight bridge between Android apps and Windows, re‑creating only the parts an app needs. It avoids booting a full Android system, so memory is used only by the apps you open. You can install apps by double‑clicking or dragging the file onto Win.apk, or by using its built‑in Store that searches Google Play’s catalogue. The program supports x86_64 native code and translates 64‑bit ARM code in the background, allowing many ARM‑only apps to run. It integrates with Windows hardware such as webcams, microphones, Bluetooth devices, Xbox controllers, location services, and the clipboard. Google sign‑in and experimental Play services are included, and the interface is available in English and Hebrew with light and dark themes.

Key features

  • Install Android app files (.apk, .apkm, .xapk, .apks) by double‑clicking, dragging, or via the built‑in Store.
  • Each app runs in its own Windows window with its own Start menu entry and taskbar icon.
  • Windows notifications are used for app alerts.
  • Access to PC hardware like webcam, microphone, Bluetooth devices, game controllers, location and clipboard.
  • Supports x86_64 apps natively and translates 64‑bit ARM apps automatically.
  • Google sign‑in and optional Play services integration.
  • Light and dark themes, with right‑to‑left layout for Hebrew.

Frequently asked questions

Is Win.apk free to use?

Yes, it is free and open source.

Is it safe to install Android apps with Win.apk?

Apps run in their own windows and use Windows security; however, only install apps from trusted sources.

How do I update Win.apk?

Updates are provided as new installer or portable zip files on the project's release page.

How do I uninstall Win.apk?

Use Windows' Add or Remove Programs for the installer version, or delete the portable folder.

Does Win.apk need an internet connection?

An internet connection is required to download apps from the built‑in Store and for Google sign‑in, but installed apps can run offline if they do not need network access.
