About Chromasmith

Chromasmith lets you edit photos on your computer without needing an internet connection or an account. It provides a library, preset film looks, texture effects and export options, all running locally.

The program is designed for anyone who wants to enhance photos with classic film aesthetics and simple editing controls. It includes 133 calibrated film presets, real grain and halation effects, RAW development, masks, retouching tools, and a local photo library. All processing happens on the device, so no uploads or subscriptions are required. The Windows version installs as a standard desktop application and registers common image file types for easy opening.

Key features

  • 133 calibrated film presets
  • Real grain and halation effects
  • RAW development and basic retouching
  • Local photo library with face and keyword detection
  • Texture tools such as sharpen and noise
  • Export at full resolution with cropping and framing options
  • Handles TIFF, JPEG, PNG, RW2 files directly
  • No account or online service required

How to install Chromasmith

  1. Click the "Download Chromasmith" button on this page. Your browser saves Chromasmith-1.0.0-windows-x64-setup.exe (1.3 GB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start Chromasmith from the Start menu or the desktop shortcut.
  4. If SmartScreen warns, choose “More info” then “Run anyway”.
  5. Open or import photos to begin editing.

Frequently asked questions

Do I need an internet connection?

No, all features work offline after the first launch.

Can I use the program for commercial projects?

Yes, the GPL‑3.0 license permits commercial use.

Which file types are supported?

The installer registers TIFF, JPEG, PNG and RW2 files for direct opening.

Is the software signed?

No, the installer is unsigned; you may need to bypass SmartScreen warnings.

Where are my edited photos saved?

You choose the location during export; the program saves full‑resolution files to the folder you select.
