About fastapi-react-admin

fastapi-react-admin provides a ready‑made back‑office system that you can run on Windows. It combines a FastAPI backend with a React 19 front‑end and includes an Electron desktop wrapper, so you get a web‑style admin console as a native Windows program.

The program is designed for teams that need a quick start for internal tools such as user management, permission control, approval processes, and file handling. It supports row‑level data permissions, multi‑tab interfaces that keep state, and an AI assistant that helps within defined limits. Storage can be configured to use S3 with resumable uploads, and it works with PostgreSQL, SQL Server or MySQL databases. A single repository contains the backend, web console, desktop template and mobile template, making it easy to develop and extend. The demo account (admin / 123456) lets you explore the interface without installing anything.

The desktop version runs as an Electron app on Windows, providing a native window, system tray icon, and the same features as the web console. It includes built‑in support for approval inboxes, workflow designers, and permission matrices, helping administrators manage organizational structures and data access without writing custom code.

The project is open source under the MIT license, free to use, and can be customized for your own business logic once the base is deployed.

Key features

  • Log in with a built‑in demo account to explore the admin console
  • Manage users, roles, and row‑level data permissions
  • Use multi‑tab interface that preserves state across tabs
  • Create and handle approval workflows with inbox and designer views
  • Upload and store files on S3 with resumable upload support
  • View system performance and capacity dashboards
  • Access the same interface as a native Windows desktop application
  • Connect to PostgreSQL, SQL Server or MySQL databases
