About Shumai

Shumai lets you keep video, image, audio and document assets in one place, view them in the browser, add frame‑by‑frame comments, and share private links. It works with local folders or any S3‑compatible storage and can be run on Windows via a portable CLI client.

Shumai provides a self‑hosted solution for media review and collaboration. You can store assets locally or on services such as AWS S3, Cloudflare R2 or MinIO. The web interface lets you preview many file types, draw annotations on individual frames, and leave timestamped comments. Teams can control who sees what with role‑based permissions and create collections of assets for clients. Optional AI agents can be mentioned in comments or chatted with to automate tasks. The system also supports automatic archival of original files, custom metadata, watermarking of shared links, 3D model turntable previews, and document‑to‑PDF conversion for easy browsing. Background processing and video transcoding run reliably using Docker or Kubernetes, but a simple Windows CLI package is available for local use.

Key features

  • Store and serve media using local disks or any S3‑compatible storage.
  • Add frame‑by‑frame drawings and timestamped comments on videos and images.
  • Create private share links and organized collections for clients.
  • Control access with team and project role‑based permissions.
  • Optional AI agent that can be mentioned in comments or chatted with for assistance.
  • Automatic archival of original files to cheaper storage while keeping proxies.
  • Preview many formats including PSD, audio, video and 3D models with turntable view.
  • Convert Office documents to PDF for in‑browser preview.

Frequently asked questions

Is Shumai free?

Yes, it is open source and free to use.

Is it safe to install on my computer?

The Windows package is a portable executable that does not modify system settings.

How do I get updates?

Download the latest Windows ZIP from the project's release page and replace the files.

How can I uninstall Shumai?

Delete the folder where you extracted the files.

Does Shumai need an internet connection?

It works offline for local storage, but features like S3 storage, AI agents and sharing require internet.
