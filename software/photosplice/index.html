About PhotoSplice

PhotoSplice is a free, open‑source image editor for Windows that aims to feel like Photoshop CS6 while being fast and simple to use. It reads and writes Photoshop files without loss, supports RAW, HDR and PDF, and offers a familiar set of tools and panels.

PhotoSplice provides a classic Photoshop‑style interface with panels, shortcuts and dialogs that match the older Photoshop workflow. It uses the Rust‑based PhotoCraft engine for speed and GPU optimisation. The program can open, edit and save PSD and PSB files, preserving layers, masks, blending modes, smart filters, text, vector paths and colour profiles, allowing seamless round‑tripping with Adobe Photoshop. In addition to PSD, it can read and write PDF, EXR/HDR and other common image formats, and includes tools for RAW development, lens correction, layer styles, filters and adjustments. The portable ZIP version runs without installation, while the MSI installer integrates with Windows for standard updates and uninstallation.

Key features

  • Open, edit and save Photoshop PSD and PSB files with full layer fidelity
  • Familiar Photoshop‑style interface with matching shortcuts and panels
  • GPU‑accelerated performance for smooth editing
  • Built‑in RAW development, lens correction and HDR tools
  • Supports PDF, EXR/HDR and other common image formats
  • Portable version available that runs without installation
