About Sucrose

Sucrose provides a way to personalize your desktop with animated and interactive wallpapers. It supports light and dark themes, multiple monitors, and any screen resolution. Users can create their own wallpapers or download them from the built‑in store.

The program lets you design wallpapers that react to audio, system status, or web content using its Audio API, System API, and embedded web view based on CefSharp. You can use any website as a wallpaper, and the engine includes support for video and GIF wallpapers via VLC. It optimizes CPU and GPU usage, automatically pauses wallpapers when a fullscreen application or game is running, and offers a power‑saving mode that pauses wallpapers on battery power. Wallpapers can be shared with friends or the Sucrose community through the Sucrose Store. The software is completely free and open‑source under the GPL‑3.0 license.

Key features

  • Supports interactive wallpapers that respond to audio and system events
  • Allows use of any website as a wallpaper via embedded WebView
  • Includes video and GIF support through VLC integration
  • Optimizes CPU/GPU usage and pauses when fullscreen apps run
  • Power‑saving mode pauses wallpapers on battery power
  • Light and dark theme options
  • Multi‑monitor and any resolution support
  • Built‑in store for downloading and sharing user‑created wallpapers
