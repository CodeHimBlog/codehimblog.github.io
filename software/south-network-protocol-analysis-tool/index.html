About South Network Protocol Analysis Tool

The South Network Protocol Analysis Tool is a one‑file Windows program for engineers and technicians who work with power communication protocols. It can decode raw hexadecimal messages, check their integrity, build new frames, and communicate via serial ports, Bluetooth or TCP, all from a single interface.

The application supports 16 different power‑line communication standards such as South Grid, State Grid, DL/T 698.45, DLT645‑2007, DLMS/HDLC and others. Users can paste a hex string, load a log file, or capture traffic and see a layered view of each field with explanations. The tool highlights the corresponding bytes when a field is selected and vice‑versa. It also offers batch processing, exporting results to Excel/CSV/JSON, and built‑in validation of start symbols, length fields, checksums and CRCs. Serial‑port and BLE communication are integrated, and a TCP monitor can reassemble streams when the optional npcap driver is installed. The program runs directly from the executable, requires no separate Python installation, and works offline. An installation package can be created with Inno Setup if a registered shortcut or start‑menu entry is desired.

Key features

  • Decode raw hexadecimal messages for 16 power‑line protocols
  • Show field‑by‑field breakdown with explanations and bidirectional byte highlighting
  • Validate checksums, CRCs and other protocol‑specific integrity checks
  • Build or modify frames using a built‑in framing template
  • Communicate via serial ports, Bluetooth LE and optional TCP capture (requires npcap)
  • Batch analyse files, clipboard content or pcap logs and export results to Excel, CSV or JSON
  • Export analysis reports and logs for documentation or further testing

Is the program free?

Yes, it is open source under the MIT license and free to use.

Is it safe to run on my computer?

The executable is self‑contained and does not require internet access; it only interacts with local serial, Bluetooth or network interfaces you choose.

Download the latest release from the project's GitHub page; the program does not have an automatic updater.
