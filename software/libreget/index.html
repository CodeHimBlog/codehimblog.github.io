About LibreGet

LibreGet provides a graphical interface for downloading videos, audio, documents and torrents from a large number of online sources. It also includes tools for subtitle handling, media conversion, transcription and simple study‑card creation, all in one desktop program.

LibreGet is built with Tauri, Rust and Svelte and runs as a native Windows application. Users paste a link or magnet/torrent file into the main window and choose the desired format or quality. The program supports high‑resolution video (up to 4K), audio‑only extraction, subtitle download, and batch operations for multiple links. Additional tools let you convert media, compress images, repair PDFs, create e‑book files, generate flashcards for spaced‑repetition learning, and even run a small server for AI‑agent integration. The software is free, open source under GPL‑3.0, contains no ads or telemetry, and keeps all downloaded files on the local computer.

Key features

  • Download videos, audio, documents and torrents from over 1,800 sites
  • Choose video quality up to 4K or audio‑only mode
  • Batch download multiple links at once
  • Built‑in subtitle download and conversion
  • Media conversion tools (video, audio, image, PDF)
  • Transcription and text‑to‑speech features
  • Create flashcards and spaced‑repetition decks
  • No account, ads or telemetry
  • Portable and installer versions available
  • Open‑source under GPL‑3.0

How to install LibreGet

  1. Go to the official GitHub release page and download the Windows installer (EXE or MSI) or the portable ZIP.
  2. Run the installer and follow the prompts, or extract the portable ZIP to a folder.
  3. Launch LibreGet from the Start menu or the extracted folder.
  4. Paste a URL or open a .torrent file to start downloading.
  5. Use the built‑in tools to convert or manage the downloaded files.

Frequently asked questions

What types of files can LibreGet download?

It can download videos, audio, images, PDFs, e‑books, torrents and many other file types from supported sites.

Do I need an account to use LibreGet?

No, the application works without any registration.

Is there any advertising or telemetry?

No, LibreGet is ad‑free and does not send usage data.

Can I use LibreGet on other operating systems?

Yes, it also has versions for macOS and Linux, but this listing covers the Windows version.

How do I update LibreGet?

Download the latest installer or portable package from the GitHub releases page and replace the existing files.
