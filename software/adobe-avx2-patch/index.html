About Adobe AVX2 Patch

Adobe AVX2 Patch changes the installer requirements of Adobe products, replacing the AVX2 check with AVX. This lets users install recent Adobe software on older processors that do not support the AVX2 instruction set.

The program opens Adobe standalone installer packages and edits the Application.json file, swapping the AVX2 requirement for AVX. It backs up the original files before making changes and can restore them with one click. The interface is built with WinUI 3 and offers light and dark themes. It supports a range of Adobe products including Photoshop, Illustrator, Audition, InDesign and others, up to 21 applications. No changes are made to the installed software itself, only the installer is patched. The tool is free, open‑source and runs as a self‑contained .NET 10 application.

Key features

  • Replaces AVX2 requirement with AVX in Adobe installer files
  • Creates an automatic backup of original installer files
  • Allows one‑click restoration of the original files
  • Supports 21 Adobe products such as Photoshop, Illustrator and InDesign
  • Simple WinUI 3 interface with light and dark mode
  • No need to modify installed Adobe programs
