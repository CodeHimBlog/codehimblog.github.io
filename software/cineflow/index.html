About CineFlow

CineFlow provides a clean interface for discovering movies and series, offering daily and personalized recommendations, natural‑language search, and a compact island mode when minimized. It pulls metadata from TMDB and falls back to Douban, and it can play streams directly or cast them to local devices.

The program shows a home screen with recommended titles, a library view and a watch history that you can cycle through with the keyboard. You can search by title, actor, genre or even by describing a mood or weather, and the results are merged and de‑duplicated. A side panel lets you collect favorites for quick access. When minimized, CineFlow turns into a small island that stays on the screen, can be dragged, expanded for search, and restored with a click.

Video playback supports HLS, DASH and FLV streams, shows episode lists for series, and remembers where you stopped so you can continue later. Playback can be cast to devices on the local network via SSDP and SOAP. The app filters ads in streams and can switch between direct, proxy or forced‑proxy connections.

Source management is handled in the settings where you can add or test multiple streaming sources, import TVBox configurations or JSON lists. Network acceleration features reduce load times for posters and streams, and all personal settings are stored locally in a JSON file.

CineFlow checks for updates and notifies you with an icon on the window. The installer version can update in place, while the portable version installs to a standard location and exits the old instance.

Key features

  • Daily and personalized movie/TV recommendations on the home screen
  • Natural‑language search that understands titles, actors, genres and mood descriptions
  • Integrated video player with support for HLS/DASH/FLV and episode selection
  • Watch history and “continue watching” that remembers the last position
  • One‑click casting to local network devices
  • Ability to add and test multiple streaming sources manually
  • Ad‑segment filtering for smoother playback
  • Minimal “island” mode that stays on screen when the window is minimized

Frequently asked questions

Is CineFlow free to use?

Yes, it is free and open source.

Is it safe to install?

The application stores its settings locally and does not modify system files.

How do I get updates?

An update icon appears in the window when a new version is available; click it to check and install.

Can I uninstall it easily?

Yes, use the standard Windows Add or Remove Programs feature for the installer version, or delete the portable folder.

Do I need an internet connection?

An internet connection is required to fetch recommendations and stream content, but the app can work offline for previously saved items.
