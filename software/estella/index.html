About Estella

Estella provides a visual editor for creating 2D and 3D games. The editor can be controlled manually or through AI agents that use the Model Context Protocol to build, test, and ship games. It supports exporting to many platforms, including web browsers, desktop, and native mobile devices.

The Estella engine combines a TypeScript SDK with a C++/WebAssembly core and a visual editor that runs as an MCP server. Users can design scenes, add entities, write scripts, and create assets such as sprites, sounds, and 3D models directly in the editor. AI agents can connect to the editor to automate tasks like building projects, taking screenshots, running playtests, and exporting builds for various platforms. The editor starts in read‑only mode and allows AI control after the user enables it via the Connect AI Tools menu. Estella aims to streamline game development by letting developers focus on content while the engine handles cross‑platform publishing.

Key features

  • Design 2D and 3D game scenes with a visual editor.
  • Write game logic using TypeScript.
  • Export games to web, desktop, and native mobile platforms.
  • Connect AI agents to automate building, testing, and asset creation.
  • Take screenshots and record gameplay directly from the editor.
  • Manage assets such as images, sounds, and 3D models within the project.
  • Preview games in Play mode with deterministic stepping and input simulation.
  • Export projects as standalone builds for various platforms.
