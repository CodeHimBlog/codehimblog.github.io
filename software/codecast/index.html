About Codecast

Codecast provides a single place where you can talk to AI coding assistants, manage tasks, view documents, handle pull requests and make decisions. It watches the history files of the agents you run and syncs their conversations in real time, so you can stay organized and keep a searchable record of every action.

The program runs a background daemon that monitors the output of AI agents on your computer or cloud host. All sessions appear in an Inbox that groups them by who needs input next, letting you focus on the most urgent items. You can pin, label, stash or kill sessions, and every message is linked back to the exact code change that caused it. Features include real‑time chat channels, transcribed calls, task tracking, document editing with version links, pull‑request integration, decision queues, automation workflows, and pages for reports or mockups. Privacy is built‑in: conversations are private by default and secrets are redacted before they are synced.

Key features

  • Inbox view that sorts all agent sessions by who needs input next
  • Searchable memory that lets you ask questions across all conversations
  • Integrated chat and transcribed calls with action items turned into tasks
  • Task and document management linked to the exact code changes
  • Pull‑request handling that connects sessions to reviews and fixes
  • Decision queue for human approvals in one place
  • Automation triggers and workflows with approval gates
  • Pages for sharing reports or mockups with version history
