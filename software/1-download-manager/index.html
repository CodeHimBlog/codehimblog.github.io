About 1 Download Manager

1 Download Manager lets you add many kinds of links to a single download queue. It splits files into parallel connections for speed, can resume interrupted downloads, and includes extensions for Chrome and Firefox to capture downloads directly from the browser.

The program supports fast, resumable HTTP/HTTPS downloads using up to 16 parallel connections. FTP links are also supported, though only plain FTP. You can add mirror links so that if the primary source fails, another is tried automatically. The app remembers your progress and can retry after a lost connection or when the computer wakes from sleep.

You can paste many links at once or use range patterns to download series of files. Queues let you schedule start and stop times, reorder items, and set actions for when a queue finishes, such as exiting, sleeping or opening the download folder. On Windows the app can run in the system tray and start with the computer.

Video and audio downloads are integrated: YouTube videos and playlists can be saved, with options for different qualities or audio‑only formats. HLS and DASH streams are merged into a single file, and torrent files or magnet links can be added, with the ability to play a video while it is still downloading.

After a download finishes you can verify checksums (MD5, SHA‑1, SHA‑256, SHA‑512). The program can automatically unzip archives and scan them with Windows Defender. Deleted files are shown struck through in the list.

Additional Windows features include a per‑download window with speed graphs and connection maps, a data‑allowance limiter, optional GitHub mirror support, and control from a phone on the same Wi‑Fi network protected by a PIN. The interface can be zoomed, and the app can start quietly in the tray.

Key features

  • Fast, resumable downloads with up to 16 parallel connections
  • Browser extensions capture downloads from Chrome and Firefox
  • Supports HTTP/HTTPS, FTP, YouTube, torrents, HLS/DASH streams and archive.org
  • Queue scheduling, start/stop times and "when done" actions
  • Play video while downloading torrents
  • Checksum verification and optional auto‑unzip with Windows Defender scan
  • Runs in the system tray and can start with Windows
  • Control downloads from a phone on the same network
