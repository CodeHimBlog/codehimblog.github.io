About DeckCraft

DeckCraft provides a modern way to build slide presentations on Windows. It supports rich text formatting, drawing tools, media insertion, animations and can open or save Microsoft PowerPoint files. The program is aimed at anyone who needs to create slides for work, school or personal projects.

DeckCraft lets you create slide decks using a variety of built‑in themes and layouts. You can draw shapes, connect them, and apply fills, gradients, shadows and other effects. Text can be edited directly on the slide with full font, paragraph and bullet controls. Images, tables, charts, audio and video files can be added and edited. The app offers transitions, animations and a presenter view for delivering slides. Finished decks can be saved as .pptx, exported to PDF, PNG, JPEG or animated GIF. An AutoRecover feature protects unsaved work. All commands are accessible through a graphical interface, making it easy for everyday users to design presentations without needing external tools.

Key features

  • Build slide decks with ready‑made themes, layouts and custom slide sizes
  • Draw and edit over 150 preset shapes with fills, gradients and shadows
  • Insert and format text, pictures, tables, charts, audio and video
  • Apply transitions, animations and use presenter view for full‑screen shows
  • Open and save Microsoft PowerPoint (.pptx) files and export to PDF, PNG, JPEG or animated GIF
