About Immage

Immage offers a straightforward workflow for photographers who prefer editing raw images in folders rather than using a catalog. It brings a selected set of darktable tools into a fixed interface, letting you adjust tone, color, detail and more with an easy‑to‑learn layout.

Immage is a free, open‑source raw photo editor aimed at photographers who want a simple, folder‑based editing experience. The program includes tone, color, detail and lens correction tools, as well as brushes, gradients, range masks and AI selections for local adjustments. You can heal, clone, apply film simulations, convert negatives, merge HDR images or panoramas, and use presets and film looks. The interface can be switched between Dark, Darktable Grey or Light themes, and custom color themes can be imported. Settings, presets, looks and keywords can be backed up to a single file and restored selectively. Immage can browse folders directly, import from a card, and optionally export to an Immich library. Export options include saving to a folder or Immich album with customizable borders and file‑name templates. Printing supports contact sheets, PDFs and soft‑proofing with your printer’s ICC profile. Edits are saved automatically in XMP side‑car files, leaving originals untouched. The Windows installer lets you choose a per‑user or all‑users installation, and updates are checked daily and can be installed from the Preferences menu.

Key features

  • Edit raw photos with tone, color, detail and lens correction tools.
  • Make local adjustments using brushes, gradients, range masks and AI selections.
  • Apply film simulations, heal/clone, convert negatives, and merge HDR or panoramas.
  • Import and export folders, cards, or Immich libraries with customizable templates.
  • Save edits automatically in XMP side‑car files, keeping originals unchanged.
  • Choose from Dark, Darktable Grey, Light or custom interface themes.
  • Back up and restore settings, presets, looks and keywords with a single file.
  • Print photos, contact sheets or PDFs with ICC profile and soft‑proof support.

Frequently asked questions

Is Immage free?

Yes, Immage is free and open‑source.

Is it safe to install?

The program is released under GPL‑3.0 and does not contain hidden malware.

How do I get updates?

Immage checks for updates daily; you can install them via Preferences › About › Updates.

How do I uninstall?

Use Windows' Add or Remove Programs to uninstall Immage like any other application.

Do I need an internet connection?

An internet connection is only needed for checking updates and optional Geoapify place‑name search.
