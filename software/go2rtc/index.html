About go2rtc

go2rtc lets you receive, convert, and rebroadcast video and audio streams from many camera models and protocols. It runs as a single executable and provides a web interface for configuration and monitoring.

go2rtc is a small, self‑contained program that can handle dozens of streaming formats and protocols without needing extra software. It can ingest streams from cameras, microphones, or files, optionally transcode them with FFmpeg, and output to popular services such as YouTube or Telegram. The web UI runs on localhost and shows active connections, statistics, and allows you to add or edit stream definitions. It supports two‑way audio, mixing multiple sources into one stream, and automatic codec negotiation. The tool can be used on its own or integrated into home‑automation platforms via its HTTP API.

Key features

  • Receive video and audio streams from many camera models and protocols
  • Re‑broadcast streams to services like YouTube or Telegram
  • Optional on‑the‑fly transcoding using FFmpeg when needed
  • Two‑way audio support for compatible devices
  • Mix multiple input sources into a single output stream
  • View live statistics for each active connection in the web UI
  • Automatic matching of client‑supported codecs and formats
  • Can be run as a standalone server or integrated via HTTP API

How to install go2rtc

  1. Click the "Download go2rtc" button on this page. Your browser saves go2rtc_win64.zip (7.7 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the go2rtc program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.
  4. Open a web browser and go to http://localhost:1984/ after starting go2rtc
  5. Use the web interface to add and configure your streams
  6. Save the configuration and the server will begin handling streams
