About phiola

phiola lets you play music files, record audio from a microphone or internet radio, and convert between audio formats. It starts quickly and uses little system resources, making it suitable for everyday listening, quick recordings, and simple format conversions.

phiola is an open‑source audio tool that works on Windows. It can open common music files such as MP3, OGG, FLAC, WAV and many others, as well as video containers that contain audio tracks. You can record directly to formats like MP3, AAC or FLAC, and convert files to a different format in one click. The program includes a graphical user interface for managing playlists and editing tags, plus a tiny background server for streaming audio over HTTP. All required codecs are bundled, so no extra installations are needed. The installer also registers file associations so you can open files by double‑clicking them.

Key features

  • Play a wide range of audio formats, including MP3, OGG, FLAC, AAC and more
  • Record audio from a microphone or internet radio to MP3, AAC, FLAC, etc.
  • Convert audio files between supported formats
  • Edit and write metadata tags and ReplayGain information
  • Stream audio over HTTP as a simple broadcast server
  • Dark‑themed graphical interface for playlist and file management
  • Very fast startup with low CPU and memory usage
