About Jenv

Jenv helps developers and anyone who works with Java to keep several JDK versions installed and switch between them quickly. It works on Windows and other platforms, but this listing is for the Windows version.

Jenv is a lightweight command‑line utility written in Go. It scans your system for installed Java Development Kits, creates symbolic links or registry entries so that the selected JDK becomes active, and updates environment variables accordingly. The tool stores its configuration once, so the chosen Java version is applied to all new console windows without further changes. It includes a modern colored output, help documentation, and supports both light and dark terminal themes. Jenv is open‑source and free under the Apache‑2.0 license.

Key features

  • Manage multiple JDK installations on a single system
  • Switch active Java version instantly via symbolic links or registry updates
  • Fast JDK scanning with concurrent processing (hundreds of milliseconds)
  • Automatic detection of Java installations across common directories
  • Command‑line interface with colored output and help commands
  • Supports Windows, Linux and macOS
  • Handles environment variables with minimal UAC prompts on Windows
  • Provides progress tracking and detailed scanning statistics

Frequently asked questions

Do I need administrator rights to use Jenv?

Administrator rights are required only when you want Jenv to modify system‑wide settings or create symbolic links.

Can Jenv manage JDKs for other users on the same computer?

Yes, it can be configured for user‑level or system‑level installations.

Is Jenv a graphical program?

No, it is a command‑line tool that runs in a terminal.

How do I add a new JDK?

Use the command "jenv add " after extracting the JDK to a folder.

Where does Jenv store its configuration?

Configuration files are kept in the user’s home directory under a hidden folder.
