About HangarAI

HangarAI is a native Windows application that runs Claude Code and Codex (beta) agents locally. It provides a shared task board, memory, and an orchestrator that coordinates multiple agent sessions, all without using Electron. You can also control the agents from a mobile app over your own network.

The program opens a single window where up to 16 terminal panes can show different AI agents working on code, answering questions, or generating images. Agents claim tasks, leave notes, and pass results back to the orchestrator, which merges changes locally. A mobile companion lets you view pending tasks, answer questions, and grant permissions from your phone. Optional cloud builds and image generation are available as paid features, billed with credits. The app does not send usage telemetry, and any optional account data is described on the privacy page. No source code is publicly available.

Key features

  • Run multiple Claude Code or Codex agents in one window with up to 16 terminals
  • Shared task board and memory that agents use to coordinate work
  • Orchestrator that merges agent deliveries locally without pushing to remote repositories
  • Mobile app integration to monitor and respond to agents from your phone
  • Optional cloud builds and image generation using credits
  • Ability to delegate sub‑tasks between agents
  • View generated images, PDFs, web pages, video and 3D models alongside code
  • Share links to generated content for temporary public access
