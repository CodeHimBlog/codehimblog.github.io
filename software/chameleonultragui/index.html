About Chameleon Ultra GUI

Chameleon Ultra GUI provides a simple Windows program that lets you work with Chameleon Ultra or Chameleon Lite hardware. The app shows tag data, lets you program new tags, and syncs settings between computers. It is aimed at hobbyists, security researchers and anyone who needs to experiment with RFID tags without using command‑line tools.

The program is built with Flutter, so it runs as a native Windows application. It connects to the Chameleon device over USB and presents the tag information in a clear window. You can scan continuously, choose tag types such as EM410X, Mifare Ultralight, Viking and others, and write data to the tags. Settings, saved cards, dictionaries and plugins can be synchronized across devices using an encrypted cloud service, or you can host your own sync server. The interface is translated into many languages via Crowdin. No additional software is required beyond the installer, and the app works out of the box after installation.

Key features

  • Scan RFID tags continuously or one‑by‑one
  • Read and write data for multiple tag types (EM410X, Mifare Ultralight, Viking, etc.)
  • View tag information and raw data in a clear window
  • Sync settings, saved cards and plugins between computers with end‑to‑end encryption
  • Supports multiple languages through community translations
  • Portable version available without installation
