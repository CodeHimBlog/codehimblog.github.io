About YukiOS

YukiOS provides a complete desktop experience inside a browser. It lets you choose between several pre‑made desktop styles and switch between them while keeping your open apps and files. All of this runs client‑side using standard web technologies, so no additional software is required beyond the browser.

YukiOS is built with vanilla JavaScript, HTML5 and CSS3 and is delivered as a single HTML file that runs in any modern browser. When you start it, you can pick a desktop mode – macOS‑style, Windows‑11‑style, ChromeOS‑style, a tiling window manager, a 3‑D desktop, or a game‑console interface called Yuki Deck. The chosen mode can be changed at any time without closing applications, and everything you open stays available across modes thanks to a persistent client‑side filesystem backed by IndexedDB.

The environment includes common desktop components such as a start menu, taskbar or dock, system tray, widgets, and a file manager. It also supports running emulators (Flash, DOS), WebAssembly applications, and standard web apps side by side. In Yuki Deck mode you get a game library, friends list, overlay with performance stats and a built‑in web browser. The macOS mode offers a fisheye dock and launchpad, while the ChromeOS mode provides a shelf‑style taskbar optimized for web workflows.

All interactions happen inside the browser tab, so there is no installation of a separate operating system. The desktop state is saved in the browser’s storage, allowing you to resume where you left off on the next visit.

Key features

  • Choose from six different desktop styles and switch between them while apps stay open
  • Persistent client‑side file system that remembers files and settings across sessions
  • Built‑in app launcher, start menu, dock or shelf depending on the chosen mode
  • Supports web apps, WebAssembly programs, and classic emulators (Flash, DOS) together
  • Yuki Deck mode offers a game library, friends activity feed and an in‑game overlay
  • System tray with quick controls for brightness, volume, battery and dark mode
  • IndexedDB‑backed storage ensures your data stays in the browser between uses
  • No additional frameworks; runs with standard JavaScript in any modern browser

Frequently asked questions

Is YukiOS free to use?

Yes, it is open source and free.

Is it safe to run?

It runs entirely in the browser and does not install system components, so it does not affect your Windows installation.

How do I get updates?

Open the application again in your browser; the latest version is loaded from the website.

How do I remove it?

Since nothing is installed, you only need to clear the browser’s site data if you want to delete saved files.

Do I need an internet connection?

An internet connection is required to load the initial files, but after that the desktop works offline using the stored data.
