About Orca

Orca provides a single interface for interacting with AI coding assistants such as Claude Code or Codex. You can chat with an agent, use a terminal view, and let the app split large tasks among several worker agents. It also supports remote execution and a companion mobile app for notifications and replies.

Orca is designed for developers and technical users who want to harness multiple AI coding agents at once. The app lets you start an agent in a chat window or a raw terminal, and you can move the conversation between the two without losing context. When a task is too big for one agent, Orca can orchestrate several worker agents in separate workspaces, collect their results, and present them back to you. You can run agents on your own computer, pair with a remote Orca server, connect to any SSH host, or assign a cloud VM to a worktree, so work continues even when your laptop is idle. A mobile companion app sends notifications when an agent needs input, allowing you to reply from your phone. The built-in review tools let you examine code diffs, add comments on specific lines, and send focused feedback to the agents.

Key features

  • Chat interface and terminal view for the same AI agent, with seamless switching
  • Orchestrates multiple worker agents to split large tasks and combine results
  • Runs agents locally, on remote servers, SSH hosts, or cloud VMs
  • Mobile app sends notifications and lets you reply to agents from any device
  • Review code diffs, annotate changes, and send feedback directly to the agent
