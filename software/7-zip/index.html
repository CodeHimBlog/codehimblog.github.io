About 7-Zip

7-Zip is a long-running file archiver for Windows. It creates and extracts archives in its own 7z format, which is designed for a high compression ratio, and it also works with widely used formats such as ZIP, TAR and GZIP.

It adds commands to the Windows Explorer context menu, includes a simple file manager, and offers a command-line version for scripts and automation. 7z and ZIP archives can be protected with AES-256 encryption.

The official website publishes separate installers for 64-bit (x64), 32-bit (x86) and ARM64 Windows, plus alternative MSI packages for managed deployment.

Key features

  • Creates and extracts 7z archives with a high compression ratio
  • Works with common formats such as ZIP, TAR, GZIP, BZIP2 and XZ
  • AES-256 encryption for 7z and ZIP archives
  • Self-extracting archives in 7z format
  • Windows Explorer context-menu integration
  • Built-in file manager
  • Command-line version for scripts and automation

How to install

  1. Open the official 7-Zip download page.
  2. Download the EXE installer that matches your Windows architecture. Most modern PCs use the 64-bit (x64) build.
  3. Run the installer and choose an installation folder.
  4. Right-click a file or archive in File Explorer to use the 7-Zip menu, or open the 7-Zip File Manager from the Start menu.
