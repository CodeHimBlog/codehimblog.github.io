About SolidCraft

SolidCraft lets you create 3D models by defining sketches and constraints, then building solids that automatically update when dimensions change. It runs on Windows as a native installer or portable zip, and also offers web and other platform versions.

SolidCraft provides a full‑featured 3D CAD environment for hobbyists, students and professionals who need a free, open‑source tool. You start with 2‑D sketches, add constraints such as dimensions or relationships, and then use operations like extrude, fillet, shell and pattern to create solid parts. All changes are recorded in a timeline, so adjusting a parameter instantly rebuilds the model. The application includes a material library, property calculations, and supports exporting designs for 3D printing or further processing. It also offers a built‑in MCP server that lets AI agents interact with the model, and a web version for quick testing without installation.

Key features

  • Sketch 2‑D profiles and apply geometric constraints
  • Build solids with extrude, fillet, shell and pattern operations
  • Parametric timeline that updates the model when dimensions change
  • View material properties and mass calculations
  • Export models for 3D printing or other CAD tools
  • Portable ZIP version for use without installation
  • Built‑in MCP server for AI‑driven modeling
  • Runs on Windows with signed installer
