About VideoLow

VideoLow provides an easy-to-use interface for common video tasks such as reducing file size, changing formats, and cutting clips. It is aimed at Windows users who need quick video processing without learning command‑line FFmpeg.

The program lets you drag and drop a video or audio file, preview it with a built‑in player, and then choose to trim, compress, or convert the media. You can select bitrate, resolution, frame rate, and codec (H.264, HEVC, AV1). Hardware acceleration is supported for NVIDIA NVENC and AMD AMF, making encoding faster on compatible GPUs. Quick‑export presets simplify common tasks, and you can also export only the audio or remove audio from a video. The interface is built with Qt and bundles FFmpeg, extracting the necessary binaries at startup.

Key features

  • Drag and drop files to load them quickly
  • Built‑in preview player for video and audio
  • Trim clips by setting start and end points during playback
  • Convert or compress files with selectable bitrate, resolution, and codec
  • Use hardware acceleration with compatible NVIDIA or AMD GPUs
  • Quick‑export presets for fast common settings
  • Export audio only or remove audio from a video
