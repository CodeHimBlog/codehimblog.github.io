About AppControl MCP Server

AppControl MCP Server runs on a Windows PC and exposes information such as which programs used CPU, GPU, RAM, disk, and security events. AI tools like Claude, Cursor, or Codex can query this data using natural language, helping you understand performance issues or security incidents.

The program works as a bridge between the AppControl desktop application and AI agents or development environments. It reads the historical monitoring data stored by AppControl—process histories, binary origins, quarantine rules, and other security events—and serves it through the Model Context Protocol (MCP). The server is read‑only, so it cannot change system settings. It can be installed as an MCPB package for Claude Desktop, added via a marketplace plugin for Claude Code, or run as a standalone executable. Once the server is running, compatible AI clients are configured to point to the executable, after which you can ask questions like which unsigned applications have run, which binaries originated from specific countries, or what caused a sudden fan noise.

Key features

  • Provides read‑only access to detailed process and security history
  • Works with popular AI assistants and IDE extensions (Claude, Cursor, Codex, Gemini, VS Code, etc.)
  • Can be installed as an MCPB package or a simple executable
  • No additional configuration needed when installed via the MCPB package
  • Allows natural‑language queries about resource usage, suspicious binaries, and quarantine events

How to install AppControl MCP Server

  1. Click the "Download AppControl MCP Server" button on this page. Your browser saves appcontrol-mcp.exe (8.1 MB), usually to your Downloads folder.
  2. Double-click the downloaded file to start AppControl MCP Server. It runs without installation; if Windows shows a security prompt, check that the file came from this page before you continue.
  3. Optional: move the file to a folder of its own (for example Documents\AppControl MCP Server) so it is easy to find next time.
  4. If installed via the MCPB package, no further configuration is needed.
  5. For the standalone executable, add the server path to your AI client’s MCP configuration as described in the client’s documentation.

Frequently asked questions

Is this program free?

Yes, it is open‑source and free to use.

Is it safe to run?

It only reads data from the AppControl app and does not modify your system.

How do I update it?

Download the latest release and replace the existing executable or MCPB file.

How do I uninstall it?

Delete the executable or remove the MCPB package from the AI client’s extensions.

Does it need an internet connection?

Only if you use the cloud MCP mode; the local server works without internet.
