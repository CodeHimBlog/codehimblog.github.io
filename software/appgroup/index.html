About AppGroup

AppGroup is a free, open‑source taskbar organizer and launcher for Windows. It lets you create groups of applications, pin a single shortcut to the taskbar, and open a popup that shows the apps in that group. The popup follows the Windows design language and works in both light and dark modes.

AppGroup helps keep a crowded taskbar tidy by allowing you to collect related programs into named groups. You can create a work group, a gaming group, a creative tools group, or any arrangement that fits your workflow. Each group appears as a single shortcut that you can pin to the taskbar or place on the desktop. Clicking the shortcut opens a popup that displays the apps in the group, and you can launch any individual app or use the optional "Launch All" button to start every app in the group at once.

The program is built with WinUI 3 and includes its own .NET 8 runtime in the bundled installers, so no additional frameworks are required. It works with the standard Windows taskbar and does not replace it. Groups can be edited by adding apps via a plus button, dragging from the Start menu, or dragging files onto the group editor. Settings let you toggle features such as alphabetical sorting and where group data is stored in the portable version.

AppGroup is released under the MIT license, meaning you can use, modify, and share it freely.

Key features

  • Create named groups of applications
  • Pin each group as a single taskbar shortcut
  • Popup UI matches Windows design, supports light and dark mode
  • Launch a single app or all apps in a group at once
  • Drag apps from Start menu or file explorer into groups
  • Portable version available without installation
  • Customizable settings including "Launch All" toggle and alphabetical sorting
  • Stores groups in AppData by default, with optional portable directory

How to install AppGroup

  1. Click the "Download AppGroup" button on this page. Your browser saves AppGroup_v1.6.0.win-x64-Bundled-Setup.exe (43.7 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start AppGroup from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. Create a new group, add your apps, and drag the group shortcut onto the taskbar.
  6. Click the taskbar icon to open the popup and launch apps.

Frequently asked questions

Do I need to install any additional frameworks?

No, the bundled installer includes the required .NET runtime.

Can I use AppGroup without installing it?

Yes, the portable ZIP version can be extracted and run directly.

How do I back up my groups?

Export groups as .agz files from the settings and import them on another machine.

Does AppGroup replace the Windows taskbar?

No, it works alongside the existing taskbar and only adds a shortcut for each group.

Is the software free?

Yes, it is free and open source under the MIT license.
