About ScreenRecorder

ScreenRecorder lets you capture the whole screen, a window, or a selected region, along with system sound and microphone input. It provides basic controls for start, stop, and settings, and supports hardware‑accelerated encoding when available.

ScreenRecorder is an open‑source screen capture tool for Windows. It uses FFmpeg libraries for video processing and supports H.264, H.265, AAC, and MP3 codecs. The interface includes a round button to start recording and a square button to stop, with a settings menu for choosing capture area, frame rate, cursor visibility, and hotkeys. Hardware encoding via NVENC or QuickSync is used if the GPU supports it; otherwise software encoding is applied. The program runs without requiring a separate .NET runtime and can be installed via an EXE installer or used as a portable ZIP.

Key features

  • Record full screen, specific window, or custom region
  • Choose video codecs: H.264, H.265 (hardware or software)
  • Choose audio codecs: AAC, MP3
  • Capture system audio, microphone, or both
  • Set cursor capture on or off
  • Adjustable frame rates from 15 to 144 fps
  • Hotkey support for start/stop
  • Hardware acceleration with NVENC or QuickSync when supported
  • Portable version available without installation

Frequently asked questions

Can I record only a part of the screen?

Yes, you can select a region, a specific window, or the entire display.

Does it need any additional runtimes?

No, the installer includes everything needed; no separate .NET runtime is required.

How do I enable hardware‑accelerated encoding?

If your GPU supports NVENC or QuickSync, the program will use it automatically; otherwise it falls back to software encoding.

Is there a portable version?

Yes, a ZIP file is provided that runs without installation.

Where can I get help if I encounter a bug?

Report issues on the project's GitHub page.
