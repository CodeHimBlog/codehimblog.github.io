About Greycard

Greycard is a free, open‑source raw photo editor that focuses on accurate colour reproduction and a familiar workflow for photographers. It runs on Windows and lets you edit raw files directly, keep edits in side‑car files, and use advanced features like AI denoising and mask‑based adjustments.

Greycard provides a Lightroom‑like interface with panels for presets, history, histogram and develop sliders. It can learn the colour look of your camera and apply it as a selectable profile. Masks support absolute white balance and colour mixing, and specialised scopes (parade, waveform, vectorscope) can be limited to masked areas for precise skin‑tone work. AI‑based denoising runs on the raw sensor data and supports many major camera brands. The editor works with side‑car files beside each raw, so your original files stay untouched and the library index makes browsing fast. You can cull shoots using embedded previews, merge brackets into HDR, create panoramas, or stack focus frames, all while keeping edits non‑destructive. Lightroom presets and catalogs can be imported, preserving ratings and collections. The program runs on the GPU via Vulkan when available, falling back to CPU rendering if not. AI mask models are downloaded on first use, and the software does not send any image data over the internet unless you enable update checks.

Key features

  • Learn and apply your camera's colour profile for consistent looks
  • Advanced masking with white‑balance control and colour mixing
  • AI denoising that works on raw sensor data for many camera brands
  • Non‑destructive side‑car edits and fast library indexing
  • HDR, panorama and focus‑stack merging directly in the editor
  • Import Lightroom presets and catalogs, keeping ratings and collections
  • GPU‑accelerated demosaic via Vulkan, with CPU fallback
  • Local AI mask generation for subjects, skies and people without sending data

  1. Click the "Download Greycard" button on this page. Your browser saves greycard-0.11.0-x86_64-windows.zip (64.3 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).

Frequently asked questions

Is Greycard free?

Yes, it is free and open source under the GPL‑3.0 license.

Is it safe to use?

The software runs locally and does not send your photos anywhere unless you enable update checks.

How do I update to a new version?

Download the latest Windows package from the project's release page and replace the existing files.

How do I uninstall Greycard?

If you used the installer, remove it via Windows Settings → Apps. For the portable version, simply delete the folder.

Do I need an internet connection?

Only to download the AI model runtime the first time you use AI masks; otherwise it works offline.
