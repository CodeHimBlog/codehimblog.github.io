About ScriptReader

ScriptReader is a Windows tool that reads handwritten notes from scanned JPEG files and produces rich‑text files with proper formatting. It is aimed at anyone who keeps handwritten notebooks and wants a digital copy without manual typing.

The program uses a deep‑learning model built with Fastai and OpenCV to segment characters and recognise handwriting. It works best with pages printed from the accompanying notebook templates that contain a dot grid for automatic alignment. Scanned images should be 300 dpi and oriented correctly. The OCR engine filters out the square‑dot grid cells that indicate mistakes, so the resulting RTF text is clean. Users can print their own notebook pages or use the provided templates, train the model on their own handwriting, and then convert the scanned pages to editable documents.

Key features

  • Converts JPEG scans of handwritten pages to RTF files
  • Preserves formatting such as bold, italics, underline and strikethrough
  • Automatically removes typographical errors marked by dot‑grid squares
  • Supports duplex scanning for faster processing
  • Works with custom‑trained handwriting models
  • Provides printable notebook templates with alignment dots
  • No installation required; runs from a portable ZIP

How to install ScriptReader

  1. Click the "Download ScriptReader" button on this page. Your browser saves ScriptReader_Win10_x86_64.zip (737.9 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the ScriptReader program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.
  4. Use the interface to load a JPEG image and choose an output location for the RTF file.
  5. The generated RTF can be opened with any word processor.

System requirements

  • Windows operating system
  • Portable ZIP file (no additional installer)
  • Scanned images in JPEG format at 300 dpi
  • Optional: Python environment with Fastai, OpenCV and glob2 if rebuilding the model (not needed for using the pre‑built version)

Frequently asked questions

What image format does ScriptReader accept?

JPEG scans of handwritten pages.

Do I need to install Python or any libraries?

No, the portable version includes everything needed to run the program.

Can I use my own handwriting model?

Yes, you can train a custom model with Fastai and replace the default one.

How do I correct mistakes in the scanned pages?

Mark errors with the square‑dot grid cells; the program will automatically filter them out.

Is the software free?

Yes, it is open‑source and free to use.
