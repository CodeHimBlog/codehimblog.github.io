About WeftCut

WeftCut is a video editing program that can be driven by an AI agent through a local MCP server. It works like a normal non‑linear editor, but external AI tools can issue editing commands in real time.

WeftCut provides a full‑featured non‑linear editing interface with timeline, keyframes, effects, captions, audio mixing and hardware‑accelerated export. All editing actions are exposed through a local MCP server, allowing any AI client such as Codex or Claude to control the editor. The AI does not run inside the app; the installer does not include model weights and optional speech or vision engines can be downloaded separately. Every edit made by an agent is recorded in the undo history, and sessions can be locked per agent to avoid accidental interference. An Agent view shows a compact preview, activity log, tacks and change diff, letting users review and audit the AI’s work before returning to the full editor.

Key features

  • Full non‑linear video editing interface
  • AI agents can control the timeline via a local MCP server
  • All editing tools (place, trim, split, keyframe, effects, captions, audio mix) are available to both humans and agents
  • Undo history records every agent action and supports checkpoints
  • Multi‑agent sessions with lockable undo to prevent conflicts
  • Agent view with activity log, tacks and change diff for review
  • Hardware‑accelerated export
  • Self‑updating Windows installer

Frequently asked questions

What does the AI agent do?

It can send editing commands such as cut, trim, add effects, or adjust audio, and the changes appear in the editor in real time.

Can I use WeftCut without an AI?

Yes, it works as a normal video editor that you can operate manually.

Does the program update automatically?

On Windows the installer updates itself in the background and applies updates when you close the app.

Are there any additional downloads needed for AI features?

The core app does not include model weights; optional speech and vision engines can be downloaded if you need them.

Is there a portable version?

The official release provides an installer; a portable ZIP is not listed.
