About MarkFlowy

MarkFlowy provides a smooth writing experience for anyone who creates notes, documentation, or articles in Markdown. It works entirely on your computer, so you don’t need an online account unless you want to use AI features.

MarkFlowy lets you switch between a WYSIWYG visual editor, plain Markdown source, and a read‑only view. You can open single files or an entire folder as a workspace, use tabs, split panes, and an outline panel to navigate large documents. The editor supports tables, task lists, code blocks, math formulas, Mermaid diagrams, and reusable snippets. Themes, custom shortcuts, and text direction can be adjusted to suit your preferences. Local history records changes and drafts, allowing you to recover work after a crash. Optional AI integration lets you chat, summarize, translate, or get Copilot‑style assistance using your own OpenAI‑compatible provider or local Ollama models. Documents can be exported as HTML, images, PDF, or, with Pandoc installed, as DOCX, ODT, and EPUB.

Key features

  • Switch easily between visual, source, and reading modes
  • Fast loading and rendering for large Markdown files
  • Organize files in a folder‑based workspace with tabs, split view, and outline navigation
  • Local history and draft recovery without cloud services
  • Customizable light/dark themes, shortcuts, and text direction
  • Optional AI chat, summarise, translate, or Copilot using your own provider
  • Export to HTML, images, PDF and, with Pandoc, to DOCX, ODT and EPUB
