About KeePassXC

KeePassXC is a community-developed, cross-platform password manager. It stores passwords, notes and other credentials in a single encrypted database file that stays on your device or in a storage location you choose, rather than in a vendor's cloud account.

It uses the KDBX database format, so databases can also be opened by other KeePass-compatible applications. Features include a password and passphrase generator, Auto-Type for filling in login forms, and optional browser integration through the KeePassXC-Browser extension.

On Windows, the official download page offers installers and portable ZIP packages for x64 and ARM64 PCs running Windows 10 or 11. A separate legacy installer for Windows 7, 8 and 8.1 is tied to an older release that is no longer supported.

Key features

  • Encrypted password database stored in a file you control
  • KDBX format compatible with other KeePass-family apps
  • Password and passphrase generator
  • Auto-Type to fill in login forms
  • Browser integration via the KeePassXC-Browser extension
  • Time-based one-time passwords (TOTP)
  • YubiKey challenge-response support
  • SSH agent integration

How to install KeePassXC

  1. Click the "Download KeePassXC" button on this page. Your browser saves the installer, usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start KeePassXC from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. Create a new database and choose a strong master password you will not forget. KeePassXC cannot recover a lost master password.

System requirements

  • Windows 10 or Windows 11 for the current release (x64 or ARM64).
  • The Microsoft Visual C++ (MSVC) Redistributable is listed as a requirement for the x64 installer and portable ZIP on the official download page.
