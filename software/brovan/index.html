About Brovan

Brovan provides a safe environment for executing untrusted programs, inspecting system calls, capturing network traffic and rendering graphics through a Vulkan translation layer. It is aimed at reverse engineers, security researchers and anyone who needs to examine how a binary works without running it directly on the host CPU.

Brovan works as an interactive emulator that can load PE, ELF, memory dumps and raw shellcode. It uses the Unicorn Engine for cross‑platform emulation and can accelerate execution with Windows Hypervisor Platform (WHP) on Windows or KVM on Linux. The built‑in Brovvulk graphics layer translates DirectX calls to Vulkan, allowing some graphical applications and games to run inside the emulator. Additional features include live syscall and API tracing, symbol resolution, DLL monitoring and network socket interception with PCAP export for traffic analysis. The project is early‑stage and focuses on providing a high‑performance, isolated sandbox for binary analysis and safe execution.

Key features

  • Load and run Windows PE or Linux ELF binaries without installing them on the host.
  • Translate DirectX graphics calls to Vulkan for rendering graphical programs.
  • Trace system calls, API functions and loaded DLLs in real time.
  • Capture and export network traffic from the emulated program as PCAP files.
  • Use hardware acceleration via WHP on Windows or KVM on Linux for faster execution.
  • Inspect memory regions and manage allocations during a session.
  • Run raw shellcode or memory dumps directly in the emulator.
  • Supports cross‑platform execution, allowing Linux binaries to run on Windows.

Frequently asked questions

Is Brovan free to use?

Yes, it is open source under the MIT license and free of charge.

Is it safe to run unknown programs with Brovan?

The emulator runs programs in a sandboxed user‑mode environment, which isolates them from the host system, but no software can guarantee absolute safety.

How do I get updates?

Download the latest release from the project's GitHub releases page; newer builds are also provided via the GitHub Actions workflow.

How do I uninstall Brovan?

Since it is a portable zip, simply delete the folder containing the program.

Does Brovan need an internet connection?

An internet connection is only required if the emulated program itself accesses the network or if you want to download updates.
