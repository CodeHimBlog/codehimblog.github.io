About TizuMark

TizuMark is a free, open‑source Markdown editor built with Rust and Tauri. It provides a fast, low‑memory experience and lets you write and preview documents in real time.

The program offers a WYSIWYG live preview so the formatted view is shown while you type. You can split the window horizontally or vertically to see source and preview side by side, and an automatic outline lets you jump to any heading. Mathematical formulas are rendered with KaTeX and diagrams can be created with Mermaid. Images can be pasted directly, and the editor can export to HTML, PNG, PDF and Word DOCX while keeping the current theme. Keyboard shortcuts are fully customizable, multiple tabs and workspaces are supported, and the interface is available in Chinese, English and Spanish.

Key features

  • Real‑time WYSIWYG preview with cursor‑focused source editing
  • Horizontal or vertical split view with synchronized scrolling
  • Automatic outline navigation for quick heading jumps
  • Built‑in KaTeX support for math formulas
  • Built‑in Mermaid support for flowcharts and diagrams
  • Drag‑and‑drop or paste images directly into documents
  • Export to HTML, PNG, PDF and DOCX preserving theme
  • Fully customizable keyboard shortcuts
  • Multiple tabs and workspace folders
  • Light, dark and system theme switching

Frequently asked questions

Can I use TizuMark without installing it?

Yes, the portable .exe runs directly after download.

Does it support exporting to Word documents?

Yes, you can export your Markdown as a DOCX file.

Are there keyboard shortcuts?

All shortcuts can be customized in the Settings menu.

Is it suitable for large documents?

The editor uses virtual rendering to keep performance smooth even with very large files.

Can I change the language of the interface?

The UI can be switched between Chinese, English and Spanish in the settings.
