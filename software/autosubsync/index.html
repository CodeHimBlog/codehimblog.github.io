About AutoSubSync

AutoSubSync is a desktop program that aligns subtitle files with video or audio tracks. It can work automatically using built‑in algorithms or let you fine‑tune timings manually. Just drag and drop your media and subtitle files and the tool does the rest.

The application combines several open‑source subtitle sync engines such as ffsubsync, autosubsync, alass and LAPSE. It supports a wide range of video, audio and subtitle formats, and can process single files or batches. Users can choose automatic synchronization, manual adjustment, or a combination of both. The interface is split into tabs for automatic, manual and batch modes, making it easy to see progress and results. All processing happens locally; no internet connection is required unless you choose to check for updates of the bundled LAPSE component.

Key features

  • Automatic synchronization using multiple subtitle engines
  • Manual timing adjustment with a visual editor
  • Batch mode for processing many files at once
  • Supports video, audio and many subtitle formats
  • Drag‑and‑drop file loading
  • Updates LAPSE component automatically when needed
  • Portable ZIP distribution, no installation required
  • Works on Windows, Linux and macOS

How to install AutoSubSync

  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).

  4. Drag and drop your video/audio and subtitle files into the window.

Frequently asked questions

What file types can I sync?

Most common video, audio and subtitle formats are supported, including MP4, MKV, MP3, WAV and SRT, ASS, SUB, IDX, among others.

Do I need an internet connection?

No, the program works offline; internet is only used to check for optional updates of the LAPSE component.

Is there a installer?

The Windows package is a portable ZIP; just extract and run the executable.

Can I process many files at once?

Yes, use the Batch mode to sync multiple video‑subtitle pairs in one operation.

Where can I get help if something goes wrong?

Check the GitHub repository issues page for troubleshooting and community assistance.
