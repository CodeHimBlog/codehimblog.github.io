About any_to_any.py

any_to_any.py lets you change files from one format to another, combine several files into one, split them or adjust video resolution. It works through a command line, a web page or a simple graphical interface, so you can choose the method that feels most comfortable.

The program supports many popular formats such as MP3, MP4, M4A, WAV, FLAC, AVI, MKV, PNG, JPG, GIF, PDF and more. You can run it as a command‑line tool for full control, open a local web page to use it from a browser, or launch a drag‑and‑drop GUI that shows progress and advanced options. The GUI lets you select input files or folders, choose the output format, set quality, resize videos, and merge or concatenate files without writing any code. The web interface works the same way but runs in your browser at http://localhost:5000. The tool relies on ffmpeg for the actual conversion, which must be installed separately and added to the system PATH.

Key features

  • Convert audio, video, image and document files between dozens of formats
  • Merge multiple files into one or concatenate them sequentially
  • Resize video files and change resolution while converting
  • Choose output quality for lossy formats
  • Use a simple drag‑and‑drop graphical interface for batch processing
  • Access the same features through a local web page or command line
  • Supports batch conversion of whole folders
  • Preserves metadata such as EXIF, PDF tags and subtitles when possible

How to install any_to_any.py

  1. Click the "Download any_to_any.py" button on this page. Your browser saves AnyToAny-1.1.8_windows.zip (92.9 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the any_to_any.py program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.
  4. After first launch, ensure ffmpeg is installed and its \bin folder is added to the system PATH as described in the documentation

System requirements

  • Python 3.10 or newer installed
  • ffmpeg executable available in the system PATH
  • At least a few megabytes of free RAM for processing files

Frequently asked questions

Is this program free?

Yes, it is free and open source under the AGPL‑3.0 license.

Is it safe to use?

The software does not contain malware; it only runs conversion commands using ffmpeg.

How do I get updates?

Download the latest Windows zip from the project's release page when a new version is published.

How do I uninstall it?

Delete the program folder and remove any ffmpeg entries you added to the PATH if you no longer need them.

Do I need an internet connection?

Only to download the program and ffmpeg; the conversion itself works offline.
