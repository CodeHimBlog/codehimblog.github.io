About windbg-mcp

windbg-mcp runs a Model Context Protocol (MCP) server on a Windows machine and forwards WinDbg/DbgEng commands to AI tools. It can control live user‑mode, kernel‑mode, crash‑dump and Time‑Travel Debugging sessions, and can be accessed locally or over the network.

The tool acts as a bridge between the powerful Windows debugging engine (WinDbg/DbgEng) and AI agents such as Claude Code, Cursor, or other MCP clients. It supports communication through stdio for local use or via an HTTP listener for remote clients. The server can attach to running processes, kernel debugging sessions, crash dumps, and even perform Time‑Travel Debugging. Advanced features include reading Secure Kernel state from Hyper‑V checkpoints and controlling virtual processors in disposable VBS VMs using built‑in h3probe providers. The driver source is included, but building, signing and installing the driver is the operator's responsibility. The package is distributed as a portable ZIP for x64 Windows and runs with elevated privileges when needed.

Key features

  • Exposes WinDbg/DbgEng to AI agents via MCP
  • Supports stdio and HTTP communication
  • Can debug user‑mode, kernel‑mode, crash dumps, and Time‑Travel Debugging sessions
  • Provides Secure Kernel access from Hyper‑V checkpoints
  • Includes built‑in h3probe driver providers for VBS VM control
  • Portable ZIP distribution, no installer required
  • Runs as a service with Administrator privileges when needed

Frequently asked questions

What does MCP stand for?

Model Context Protocol, a way for external tools to communicate with a server.

Do I need to install WinDbg separately?

Yes, the WinDbg engine must be present on the machine for the server to function.

Can I run windbg-mcp without administrator rights?

Basic stdio usage works without elevation, but kernel debugging and driver operations require Administrator privileges.

Is there an installer?

No, the program is distributed as a portable ZIP; just extract and run.

Which AI tools can connect?

Any MCP‑compatible client, such as Claude Code, Claude Desktop, or custom tools that implement the MCP protocol.
