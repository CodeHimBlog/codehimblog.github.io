About Meeting Media Manager

Meeting Media Manager helps users prepare and show media for congregation meetings. It fetches the latest media from the official website, keeps it up to date and provides simple playback controls, thumbnails and external‑monitor handling. The app works on Windows and can be used for in‑person or hybrid meetings.

The application is designed for members of Jehovah’s Witnesses who need to present media during meetings. It can download media in any language offered by the official website and lets users manage several congregations from one place. Media items are shown as thumbnails that can be zoomed, panned and trimmed. Users can drag‑and‑drop items to reorder them, add extra files such as PDFs or JWPUB books, and set background music that stops automatically before a meeting starts. The program recognises external monitors, can share the screen on Zoom and switch scenes in OBS Studio automatically. It also syncs with cloud folders like Dropbox or OneDrive, making it easy to keep media consistent between home and the meeting hall. Special events can be created with custom titles, colours and repeat options. The interface is available in many languages and complies with the terms of use of the source website.

Key features

  • Automatically downloads and updates meeting media in any available language
  • Shows media thumbnails with zoom, pan and start/end time controls
  • Simple playback buttons and drag‑and‑drop sorting of items
  • Integrates with Zoom for screen sharing and with OBS Studio for automatic scene changes
  • Detects external monitors and can present the official website on them
  • Syncs media folders from cloud services such as Dropbox or OneDrive
  • Supports adding extra files like PDFs, JWPUB and audio recordings
  • Allows creation of special events with custom titles and colours
