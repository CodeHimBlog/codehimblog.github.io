About DeskX Wallpaper Engine

DeskX Wallpaper Engine replaces the static desktop background with dynamic media and provides a modular widget overlay. It runs behind desktop icons using the Win32 WorkerW technique, so icons and the taskbar remain visible. Widgets can be placed in three Z‑order layers, are draggable, and can show clocks, weather, calendars, and more, with separate settings for each monitor.

The program is built with Electron and bundles its own Chromium and Node.js runtime, so no external dependencies are required. It supports static images, animated GIFs, a wide range of video formats, and full HTML pages, allowing CSS animations, WebGL, and JavaScript to run as wallpapers. Multi‑monitor configurations are fully supported: you can use the same wallpaper on all screens, assign different wallpapers per monitor, or span a single image across the whole virtual desktop. The widget system offers a 3‑layer Z‑order (below apps, above taskbar, topmost) and includes click‑through areas so the desktop remains usable. The portable ZIP version runs without installation, while the installer sets up shortcuts and automatic updates.

Key features

  • Dynamic wallpapers: images, GIFs, videos, and interactive HTML pages
  • Full multi‑monitor support with per‑monitor or spanning modes
  • Three‑layer widget overlay (below apps, above taskbar, topmost)
  • Draggable, live widgets such as clocks, weather, and calendars
  • Click‑through transparent areas to keep desktop icons usable
  • Standalone installer and portable ZIP options
  • No external runtimes required; bundles Chromium and Node.js
  • Sound control and looping for video wallpapers

Frequently asked questions

Can I use DeskX without installing it?

Yes, download the portable ZIP, extract it, and run DeskX.exe directly.

Which media formats are supported for wallpapers?

Images (PNG, JPG, WebP, etc.), animated GIFs, videos (MP4, WebM, MKV, AVI, MOV, WMV, FLV), and HTML pages.

Does DeskX work on multiple monitors?

Yes, it supports per‑monitor configurations, spanning across monitors, and shows a monitor dashboard for layout.

Will the widgets interfere with my normal desktop use?

Widgets have click‑through areas, so empty parts let mouse clicks reach desktop icons and other windows.

Do I need to install any additional software?

No, DeskX includes all necessary runtimes in its package.
