About Schreibzeug

Schreibzeug provides a desktop application for Windows that lets you create and edit common office documents (.docx, .xlsx, .pptx, PDF) on your own computer. It supports real‑time collaboration, keyboard‑only operation and optional AI assistance, while keeping your files private.

The program is an open‑source alternative to cloud office services. Documents stay in their original formats, so they can still be opened with Microsoft Office or LibreOffice. A small built‑in server runs locally, storing files in a folder you choose, and uses a SQLite database. Real‑time editing shows other users' cursors and comments without needing a separate document server. Features include spell checking, templates, mail merge, charts, pivot tables, slide designs, PDF form filling, digital signatures, OCR, and markdown preview. The software is GDPR‑friendly, has no telemetry, and can be extended with AI assistants that require your approval for changes.

Key features

  • Edit Word, Excel and PowerPoint files directly in the desktop app
  • Real‑time collaboration with comments and live cursor names
  • Fill, sign and annotate PDFs, including OCR for scanned pages
  • Create charts, pivot tables and use formulas in spreadsheets
  • Build slide presentations with layouts, transitions and speaker notes
  • Live preview for markdown and plain‑text files
  • Keyboard‑only navigation for accessibility
  • Optional AI assistants for content generation, with user consent
