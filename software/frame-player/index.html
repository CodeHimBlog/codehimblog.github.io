About Frame Player

Frame Player lets you watch videos from many sources in a single window. It can open files on your computer, stream from URLs, or play magnet torrents while they download. The player also supports casting to Chromecast, DLNA TVs, and other devices, and includes a watch‑together mode that synchronises playback with another user.

The program is built with Tauri 2 and libmpv, so it inherits mpv’s wide format support, hardware acceleration and HDR capabilities. The interface is rendered with HTML over a native video view, giving a modern look while keeping precise frame‑accurate control.

Key features include: - Play local video files, network streams and torrent magnet links without leaving the app. - Watch together with a friend using a short code; playback position, pauses and seeks stay in sync. - Cast video to Chromecast, DLNA or AirPlay devices without re‑encoding; if needed the file is remuxed quickly. - Chapter navigation and a skip‑intro button help you jump over openings, recaps or credits. - Automatic subtitle search on OpenSubtitles using the file’s hash for exact matches. - Portable ZIP versions are available; just extract and run, settings are stored beside the executable. - Automatic in‑app updates when a new release is published. - Customisable hotkeys and a settings panel for subtitle appearance, video output and more.

The player is open‑source under the GPL‑3.0 license, meaning anyone can use, study, modify and redistribute the software as long as they keep the same license for derived works.

How to install Frame Player

  1. Go to the official GitHub release page and download the installer (x64 or ARM64) or the portable ZIP for your system.
  2. If you downloaded the installer, run the .exe file and follow the on‑screen prompts.
  3. If you downloaded the portable ZIP, extract its contents to any folder.
  4. Launch FramePlayer.exe from the installation folder or the extracted folder.
  5. The application will start and you can begin adding videos or torrents.

Frequently asked questions

Can I use Frame Player without installing it?

Yes, download the portable ZIP, extract it and run the executable directly.

Does the player support hardware‑accelerated decoding?

Yes, it uses libmpv which provides hardware acceleration and HDR support.

How does the watch‑together feature work?

Share the six‑character code with a friend; both players sync playback position, pauses and seeks in real time.

Can I cast videos that are still downloading?

Yes, torrents can be cast while they are being downloaded, using the same piece‑priority stream.

Are subtitles automatically loaded?

The player can search OpenSubtitles by the video’s hash and load matching subtitles automatically.
