About TypeWhisper

TypeWhisper runs on Windows and provides real‑time dictation, audio transcription and text‑processing workflows without sending data to the cloud unless you choose a cloud provider. It works with a global shortcut, shows an overlay with live transcription, and can insert the text directly into any application.

The program uses a WinUI 3 interface and can operate with local transcription plugins or cloud services. You can record from the microphone or system audio, transcribe recordings, and export the results as plain text or timed subtitles when supported. Built‑in workflows let you rewrite, translate, or otherwise process the transcribed text. Personal terms, corrections and reusable snippets are stored locally, and a history view lets you browse past transcriptions. Additional functionality is available through optional plugins for transcription models, language‑learning models, and other text‑processing actions. An optional local HTTP API and a bundled command‑line client allow external control of the app.

Key features

  • Dictate into any Windows program using a global shortcut and see live transcription in an overlay.
  • Record microphone or system audio and transcribe files to text or subtitles.
  • Apply built‑in workflows for translation, rewriting and other text processing.
  • Save personal terms, corrections and reusable snippets for quick insertion.
  • Extend functionality with optional plugins for different speech models and text‑processing tools.
  • Control the app via a local HTTP API or the bundled CLI.
  • Automatic insertion of transcribed text according to your output settings.

How to install TypeWhisper

  1. Click the "Download TypeWhisper" button on this page. Your browser saves com.typewhisper.sherpa-onnx-1.4.1-win-x64.zip (64.9 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the TypeWhisper program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.

System requirements

  • x64 Windows system (minimum build 19041).
  • .NET Runtime 10 (for older releases) or .NET Runtime 11 (for current release).
  • Internet connection required for first‑time plugin download and model assets.
  • At least a few hundred megabytes of free disk space for plugins and model files.

Frequently asked questions

Is TypeWhisper free?

Yes, the application is open source and free to use.

Is it safe to install?

It is released under the GPL‑3.0 license and does not require any external services unless you choose a cloud provider.

How do I update the program?

Download the latest Windows package from the project's release page and replace the existing files.

How can I uninstall TypeWhisper?

Delete the program folder and any shortcuts you created; no additional cleanup is required.

Do I need an internet connection?

Only for the initial download of plugins and model files; local plugins work offline afterwards.
