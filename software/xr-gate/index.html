About XR Gate

XR Gate is a free, open‑source software package that acts as a bridge between limited or unsupported XR hardware and Windows VR platforms. It captures camera and IMU data, processes it, and presents it to SteamVR, OpenXR or other VR applications as if the hardware were natively supported. The project is aimed at users who want to use devices such as XREAL Ultra glasses, Leap Motion cameras or custom trackers for VR gaming and research without needing proprietary drivers.

The program works by running a capture service that reads stereo camera images and optional IMU data, then streams the information to a client library. The client normalises the data, predicts movement, and provides virtual controller input. Supported features include:

* Full 6DoF head tracking using stereo cameras and optional IMU integration. * Image‑based hand tracking via the Mercury/ONNX backend. * Optional body‑tracking using the FRAME backend. * Compatibility with a range of controllers, including Samsung Gear VR and generic Bluetooth gamepads. * Integration with SteamVR/OpenVR and OpenXR runtimes, allowing existing VR games to work. * Stereo video streaming and optional video overlay for mixed‑reality experiments. * Real‑time depth grid and spatial mesh output for research purposes.

The Windows version is packaged as a portable ZIP that runs under WSL2 with USB‑IP support, providing the necessary driver bridge for USB‑connected devices. No vendor‑specific SDKs are required, and the system can be used with a variety of headsets and tracking setups.

Features are implemented in C++ for low‑latency capture and in Python for flexible SDK access, making the stack both performant and extensible.

The project is licensed under the MIT license and is maintained on GitHub.

Key features

  • Enables VR/AR headsets that lack native Windows drivers to work with SteamVR and OpenXR.
  • Provides 6DoF tracking using stereo cameras and optional IMU data.
  • Adds hand tracking through image analysis.
  • Supports optional body tracking from stereo camera frames.
  • Allows use of various Bluetooth or USB controllers as VR input devices.
  • Streams stereo video and can overlay it in VR applications.
  • Generates real‑time depth and spatial mesh data for research.
  • Runs as a portable package under WSL2 with USB‑IP support.

Frequently asked questions

Is XR Gate free to use?

Yes, it is open‑source and free under the MIT license.

Is it safe to run on my computer?

The software is community‑maintained, does not contain hidden code, and runs only the hardware you connect.

How do I get updates?

New releases are published on the project's GitHub page; download the latest ZIP and replace the existing files.

How do I uninstall XR Gate?

Delete the folder where you extracted the portable ZIP.
