About Watt Toolkit

Watt Toolkit (formerly Steam++) provides a collection of tools that help Windows users manage their Steam, Epic, Ubisoft and other game accounts. It adds features like fast account switching, game library editing, download monitoring, cloud‑save handling and network acceleration, all from a single desktop program.

The program works with the official Steam client and other game platforms that are already installed on the PC. It lets you quickly change between multiple accounts, edit the names and cover images of games in your library, monitor download progress and shut down the PC when downloads finish, and simulate game runs to earn playtime or card drops without installing the game. It also includes a token manager that stores mobile authenticator codes for Steam, Google, and other services, and it can accelerate access to game stores by running a local reverse proxy. All features are provided through built‑in plugins that can be enabled or disabled by the user.

Key features

  • Switch between multiple Steam, Epic, Ubisoft and other game accounts with a single click.
  • Edit game titles and custom cover images in your Steam library.
  • Track download progress and automatically shut down the PC when a game finishes downloading.
  • Simulate running a game to record playtime or earn Steam card drops without installing it.
  • Manage Steam cloud saves, upload or delete files as needed.
  • Store and generate mobile authenticator codes for Steam, Google and other services.
  • Accelerate access to game store websites using a local proxy.
  • Enable or disable individual plugins to customize the toolbox.
