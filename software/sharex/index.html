About ShareX

ShareX captures your screen in many ways: a selected region, a window, the full screen or a scrolling page. It can also record the screen as a video or animated GIF.

After each capture, ShareX can run a sequence of actions that you configure, such as annotating the image, copying it to the clipboard, saving it, or uploading it to one of many supported services. It also includes extra tools like a colour picker, screen ruler and text recognition (OCR).

Because ShareX is highly configurable, it suits both quick everyday screenshots and repeatable documentation workflows.

Key features

  • Region, window, full-screen and scrolling capture
  • Screen recording to video or animated GIF
  • Image editor for annotation
  • Configurable after-capture and after-upload tasks
  • Uploads to many supported destinations
  • Text recognition (OCR)
  • Colour picker, screen ruler and other tools
  • Custom hotkeys for every capture mode

How to install ShareX

  1. Click the "Download ShareX" button on this page. Your browser saves ShareX-22.4.0-setup-x64.exe (138.7 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start ShareX from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. Check that the release is a stable release and not a pre-release, unless you want to test new features.
