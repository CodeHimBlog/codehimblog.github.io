About HyCanvas

HyCanvas is a web‑based design editor that lets you create social media graphics, posters, presentations, videos, whiteboards, documents and spreadsheets. It offers many ready‑made templates and lets you export your work in common formats without watermarks.

HyCanvas provides a full‑featured design environment similar to popular online design tools. You can start from over 140 built‑in templates or a blank canvas, edit shapes, text, images, charts and more, and organise your work with layers and a floating toolbar. The editor includes a multi‑track video timeline, a block‑style document editor, and a spreadsheet with formulas. Real‑time collaboration lets multiple users edit together, see each other's cursors, comment, and manage version history. Workspaces support role‑based access, single sign‑on, two‑factor authentication and brand guidelines. AI assistance can generate content using your own API key, while many features work without any key. All designs can be exported as PNG, JPG, PDF, SVG, PPTX, MP4, GIF and other formats, and each project can be saved as a portable .hyc file.

Key features

  • Create graphics, presentations, videos, whiteboards, documents and spreadsheets in one web app
  • Choose from 140+ templates or start from a blank canvas
  • Export designs as PNG, JPG, PDF, SVG, PPTX, MP4, GIF and more without watermarks
  • Real‑time co‑editing with presence cursors, comments and version history
  • Multi‑track video editing with trims, transitions, keyframes and screen/webcam recording
  • AI‑powered content generation using your own provider key or built‑in Assist tools
  • Workspace management with roles, single sign‑on, two‑factor authentication and brand kits

Frequently asked questions

Is HyCanvas free?

Yes, it is open‑source and free to use.

Is it safe to run on my PC?

The program runs inside Docker containers, keeping it isolated from the host system.

How do I get updates?

Pull the latest Docker images and restart the containers with docker compose pull && docker compose up -d.

How do I uninstall HyCanvas?

Stop and remove the Docker containers and delete the folder where you stored the compose files.

Do I need an internet connection?

Docker needs to download images initially, but after that the editor works locally on your machine.
