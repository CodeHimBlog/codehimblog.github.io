About MarkerOn

MarkerOn lets you quickly annotate your screen for presentations, teaching, meetings or screen recordings. It stays in the system tray and is activated with a hotkey, so you can draw over any application without opening a separate window.

MarkerOn is an open‑source, free utility that runs quietly in the background. After installing, the program places an icon in the system tray; no main window appears. Press Ctrl + Shift + D to enter annotation mode, then use the toolbar or keyboard shortcuts to choose from eleven drawing tools such as pen, highlighter, arrow, rectangle, ellipse, text and stamp. Annotations can be drawn over any part of the screen, including the taskbar, and you can keep them visible while interacting with underlying applications by pressing X. The tool offers stroke styles, tapered ink, and a selection mode for moving or deleting groups of annotations. Settings let you adjust brush width, colors and other preferences, and all configuration is stored next to the executable, making the portable version fully self‑contained.

Key features

  • Activate annotation mode instantly with a keyboard shortcut
  • Draw with pen, highlighter, shapes, arrows, text and stamps
  • Annotations appear over any window, even the taskbar
  • Click‑through mode lets you interact with apps while keeping drawings visible
  • Stroke styles include solid, dashed and dotted, with tapered ink option
  • Select, move or delete multiple annotations with the Select tool
  • Settings are saved locally and work across installer, Microsoft Store and portable versions

How to install MarkerOn

  1. Click the "Download MarkerOn" button on this page. Your browser saves MarkerOn_2.33.0_x64-setup.exe (2.9 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start MarkerOn from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. After launch, MarkerOn runs in the system tray with no visible window
  6. Press Ctrl + Shift + D to start annotating
  7. Use Space to open the toolbar and X to enable click‑through mode
