About DMR Studio

DMR Studio provides a graphical interface for monitoring livestream channels, setting up automatic recording, splitting recordings into segments, capturing on‑screen chat, rendering the chat onto the video and uploading the result. It is aimed at users who want to save livestreams without manually starting and stopping a screen recorder.

The software combines several steps of livestream archiving into one program. Users add the URLs of the streams they want to follow, configure when recording should start, and the program will monitor the channel and begin recording automatically. Recordings can be split into smaller files, and the on‑screen chat (danmaku) is captured and later rendered onto the video with adjustable size, opacity and position. After rendering, the video can be uploaded to a chosen platform directly from the app. The interface is designed to be simple enough for beginners, with language and theme options, and a task list that shows the status of recordings, rendering jobs and uploads.

Key features

  • Automatically start recording when a livestream goes live
  • Split recordings into separate files based on time or size
  • Capture on‑screen chat (danmaku) while recording
  • Render captured chat onto the video with adjustable font size, opacity and area
  • Manage recording, rendering and upload tasks in a single window
  • Upload finished videos to supported services directly from the app
  • Simple language and theme settings for easy use
