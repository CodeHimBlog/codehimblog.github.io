About VLC-RPC

VLC-RPC connects VLC Media Player with the Discord desktop client. When you play a video or music file in VLC, the program updates your Discord status to show what you are watching or listening, and it can display the album cover automatically.

VLC-RPC is a small helper that runs alongside VLC. It reads the media information from VLC and sends it to Discord using the rich‑presence API. The project is a fork of an earlier VLC Discord integration and adds automatic album‑art support. It works with the standard VLC installation and the official Discord client. Configuration is stored in a simple JavaScript file that is created the first time the program runs. The tool does not stream media or modify VLC; it only updates your Discord status. It is free, open‑source software released under the MIT license.

Key features

  • Shows the title of the currently playing video or song in Discord
  • Displays album art automatically when available
  • Updates Discord status in real time as playback changes
  • Simple configuration file created on first run
  • Works with any media played in VLC
  • No need to modify VLC settings

How to install VLC-RPC

  1. Click the "Download VLC-RPC" button on this page. Your browser saves vlc-rpc-v1.3.1-bundled-win-x64.zip (31.4 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the VLC-RPC program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.
  4. When you launch VLC‑RPC for the first time it creates a config/config.js file. Edit this file to change options such as display format or hide certain details.
  5. After starting, the program runs in the background and updates your Discord status while VLC is playing.

Frequently asked questions

Is VLC‑RPC free to use?

Yes, it is completely free and open source.

Is it safe to run?

It only reads information from VLC and sends it to Discord; it does not access your files or the internet beyond Discord.

How do I update to a newer version?

Download the latest release archive, unzip it, and replace the old files.

How can I uninstall VLC‑RPC?

Delete the program folder and the config file you created.

Do I need an internet connection?

Yes, Discord must be online for the status to appear.
