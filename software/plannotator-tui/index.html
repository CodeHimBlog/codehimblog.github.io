About Plannotator TUI

Plannotator TUI runs in a command‑line window and provides a simple interface for reviewing Markdown documents. You can select text, add comments, mark parts as "looks good" or delete them, attach images, and copy the results to the clipboard or send them to an AI coding assistant.

The tool displays a file tree on the left and the contents of the selected Markdown file on the right. Use the mouse or keyboard to select a region, then press a to mark it as approved, c to add a comment, or d to delete it. Annotations are saved instantly as JSON. Press E to copy all feedback to the clipboard, S to send it to a configured coding agent, and q to quit. Images can be attached to notes with I, supporting common formats such as PNG, JPEG, GIF, WebP, BMP and SVG. The program works without any additional runtime; it is a single static binary built with Rust.

Key features

  • Open a folder or single Markdown file and see a navigable file tree.
  • Select text and mark it as approved, comment on it, or delete it.
  • Attach images to notes using common image formats.
  • Export all annotations as numbered feedback copied to the clipboard.
  • Send the feedback directly to a coding agent or external command.
  • All changes are saved automatically as JSON.
  • Works entirely in the terminal with mouse or keyboard navigation.
  • No additional runtime or installation steps required.

Frequently asked questions

Is Plannotator TUI free?

Yes, it is open source and free to use.

Is it safe to run on my computer?

The program is a single static binary with no external dependencies, so it runs locally without contacting any servers unless you choose to send feedback.

How do I get updates?

Download the latest Windows executable from the project's release page and replace the old file.

How do I uninstall it?

Delete the executable file you placed on your system.

Do I need an internet connection?

Only if you want to send feedback to a coding agent or download updates; otherwise it works offline.
