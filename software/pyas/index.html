About PYAS Security

PYAS Security is a Windows security suite that runs on the desktop and offers multiple layers of protection. It scans files locally with machine‑learning models and YARA signatures, can submit suspicious items to an online service, and uses a native driver to block harmful actions in real time.

The application provides static and behavioral detection. Local scans examine Portable Executable files using feature extraction and an ONNX model, while YARA rules match known malicious patterns. Digital signatures are verified, and optional cloud analysis adds another check. A C++ minifilter driver monitors file, process, registry and memory activity, allowing the program to block or quarantine threats before they execute. Additional tools let users manage startup items, clean up the system, repair damaged settings and back up the MBR. The interface is built with WebView2 and lives in the system tray, giving quick access to scans, quarantine, and logs. PYAS is intended for users who want an extra layer of protection and for researchers interested in studying malware detection on Windows.

Key features

  • Scans files locally with machine‑learning and YARA rules
  • Optional cloud submission for deeper analysis
  • Real‑time monitoring of processes, files, memory and network activity
  • Kernel‑level driver that can block or quarantine threats
  • Built‑in tools for startup management, system cleanup and repair
  • Quarantine area to isolate suspicious files
  • Activity logs and reports for reviewing alerts
  • Simple tray icon for quick access to scans and settings
