About InstallerClean

InstallerClean scans the hidden C:\Windows\Installer folder, identifies files that are no longer needed by any installed program, and lets you delete or move them to free up space.

The program focuses on a single task: cleaning up leftover installer files that accumulate as you install and update software. It reads the Windows Installer database and registry to determine which files are still required. After a quick scan it shows a list of unneeded files, their sizes, and offers options to delete them or move them elsewhere. It works as a graphical application and also provides a command‑line tool for scripting. The tool is open source, free, and distributed as an installer, a portable executable, a slim version, and a separate CLI binary.

Key features

  • Scans C:\Windows\Installer for unneeded files
  • Shows detailed information about each file
  • Allows deletion or relocation of safe files
  • Provides both graphical UI and command‑line interface
  • Portable version runs without installation
  • Uses Windows Installer database to ensure safety
  • Generates a report of reclaimed space
  • Supports multiple languages in the UI

Frequently asked questions

Is it safe to delete files identified by InstallerClean?

Yes, the program only offers files that are not referenced by any installed product.

Do I need to be an administrator?

Running the scan requires administrative privileges because it accesses system folders.

Can I run it on a different Windows account?

The tool checks the installer database for all accounts, so it works regardless of which user is logged in.

Does it create a backup before deleting?

No automatic backup is made; you can choose to move files instead of deleting them.

Is there a command‑line version?

Yes, the installerclean-cli.exe provides the same functionality for scripts.
