About Quiesce

Quiesce is a lightweight system cleaner and RAM optimizer that runs from a single executable. It provides a terminal menu with customizable cleaning steps to free disk space and improve performance.

Quiesce offers a fast, no‑install solution for keeping a Windows PC tidy. It can delete temporary files, user temp files, prefetch data, error reports, delivery‑optimization cache, Windows Update cache, log files, installer leftovers, DNS cache, and can free unused RAM. Optional steps include emptying the Recycle Bin and performing a deep Windows Disk Cleanup. Settings are saved and can be edited in the menu. The tool runs with administrator rights only when needed and restores any paused services after cleaning. It supports English and Spanish and can be extended to other languages. Updates are handled by the program itself, which verifies download checksums before installing.

Key features

  • Removes Windows and user temporary files
  • Clears prefetch, error reports, and Windows Update caches
  • Empties DNS cache and frees unused RAM
  • Optional Recycle Bin emptying and deep disk cleanup
  • Saves custom settings for future runs
  • Runs from a single portable executable
  • Updates itself and verifies SHA‑256 checksums
  • Supports English and Spanish interfaces

Frequently asked questions

Do I need to be an administrator to use Quiesce?

Administrator rights are only required when the program performs cleaning actions; the installer itself does not need admin rights.

Can I run Quiesce without installing it?

Yes, the program is a single executable that can be run directly after download.

How does Quiesce free RAM?

It asks Windows to release memory that is allocated but not actively used and shows how much was freed.

Are my files safe during cleaning?

By default the Recycle Bin is left untouched, and the deep cleanup step is disabled unless you enable it.

How do I update Quiesce?

Run "qc -u" in a terminal; the program will download the latest release, verify its checksum, and replace the old executable.
