About VLC Win10smtc

VLC Win10smtc lets VLC work with the Windows media keys and the system media overlay. When you play a video or music in VLC, the standard Windows controls show the correct title, artwork and playback position, and you can control playback with the keyboard or hardware buttons.

The plugin is a small DLL that VLC loads as a misc plugin. It communicates with the Windows System Media Transport Controls (SMTC) so that VLC appears as a regular media source to the operating system. It supports VLC 3.0.x and VLC 4.0.0‑dev builds. The plugin must match the architecture of the VLC executable (x86, x64, or ARM64). After installation you enable the feature in VLC's advanced preferences under Interface → Control Interfaces. The plugin is open‑source and released under the GPL‑3.0 license.

Key features

  • Shows track title, artist and album art in the Windows media overlay
  • Updates playback position and progress bar accurately
  • Enables hardware media keys (play, pause, next, previous, stop)
  • Works with both VLC 3 and VLC 4
  • Falls back to VLC's own icon when no album art is available
  • Displays correct status only when VLC can perform the action
  • Provides error messages if the plugin architecture does not match VLC

How to install VLC Win10smtc

  1. Click the "Download VLC Win10smtc" button on this page. Your browser saves libwin10smtc_plugin_v5.0.0_x64.zip (1.3 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the VLC Win10smtc program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.
  4. Copy the DLL to \plugins\misc.
  5. Restart VLC.
  6. Open Advanced Preferences → Interface → Control Interfaces, check "Windows SMTC integration" and save.

Frequently asked questions

Which VLC versions are supported?

VLC 3.0.x and VLC 4.0.0‑dev nightly.

Do I need a separate installer?

No, the plugin is a portable DLL that you copy into VLC's plugins folder.

What if my VLC is 64‑bit but my Windows is 32‑bit?

The plugin must match VLC's architecture, not the operating system.

Do I need the Visual C++ Redistributable?

Yes, the same version and architecture as your VLC installation.

Can I use the plugin with other media players?

It is designed specifically for VLC and will not work with other players.
