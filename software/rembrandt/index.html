About Rembrandt

Rembrandt is a free, open‑source photo editing program for Windows. It lets you edit photos, work with RAW files, apply AI‑based masks, and use tools like super‑resolution, all without needing to sign up for any service.

Rembrandt provides a modern editing interface where you can open images, adjust colour and tone with sliders, and use AI prompts to apply effects such as golden hour lighting or lens blur. The program includes a library view for organizing albums, searching, sorting and one‑click deletion. Masks can be created with brushes, gradients, or AI‑generated subject and depth selections. Super‑resolution upscales images 2× or 4× using your GPU. All edits are saved as XMP side‑car files, leaving the original photos untouched. The software runs locally on Windows and does not track usage or require an internet connection for basic editing.

Key features

  • Open and edit RAW photos with colour and tone sliders
  • Use AI prompts to apply complex effects quickly
  • Create masks with brush, gradient, or AI‑generated subject and depth
  • Upscale images with GPU‑accelerated super‑resolution (2× and 4×)
  • Organise photos in a library with albums, search, sorting and one‑click delete
  • Edits are saved as XMP side‑car files, keeping originals unchanged

How to install Rembrandt

  1. Click the "Download Rembrandt" button on this page. Your browser saves Rembrandt-windows-x64-setup.exe (106.4 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start Rembrandt from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. When first launching, you may need to click “More info → Run anyway” to bypass the unsigned‑application warning.
