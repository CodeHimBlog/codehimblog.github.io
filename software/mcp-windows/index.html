About Mcp Windows

Mcp Windows provides a way for AI assistants to interact directly with Windows programs. It uses the Windows UI Automation API to locate buttons, fields, and other controls by name, so tasks like filling forms, reading tables, or saving files can be performed programmatically. The server can be used via the MCP protocol or a command‑line interface, and it works with popular AI tools such as GitHub Copilot, Claude, and Cursor.

The software runs as a standalone server that exposes automation capabilities to AI agents. It discovers UI elements, performs actions like clicking or typing, and can return the state of controls. Screenshots, mouse, and keyboard actions are also supported for cases where UI information is not available. The server includes its own .NET runtime, so no separate installation is required. It is distributed as portable ZIP files for x64 and ARM64 architectures. The project is open source under the MIT license.

Key features

  • Automates Windows UI elements by name using UI Automation API
  • Performs clicks, typing, and selection on identified controls
  • Reads text, tables, and control states directly
  • Supports screenshots, mouse, and keyboard actions when needed
  • Provides both MCP protocol and a command‑line interface
  • Works with major AI assistants like Copilot, Claude, and Cursor
  • Portable ZIP packages for x64 and ARM64 CPUs
  • Includes its own .NET runtime, no extra installation required

Do I need to install .NET separately?

No, the server package includes the required .NET runtime.

Can I use the tool with any AI assistant?

It works with assistants that support the MCP protocol or can invoke the CLI, such as GitHub Copilot, Claude, and Cursor.
