About DartPDF

DartPDF provides a straightforward way to work with PDF files on your computer. You can open a PDF, add notes, fill out form fields, place signatures, remove sensitive information, and reduce file size, all within a single program.

The program is built with Flutter and runs entirely on your device, so no files are uploaded to the cloud. It offers a full set of annotation tools, form filling capabilities, and page manipulation features. You can insert additional PDFs, reorder pages, and save changes back to the original file. The editor also includes a file‑size reduction tool with several quality presets, allowing you to create smaller PDFs for sharing or storage. All operations are performed locally, keeping your documents private.

Key features

  • Add text notes, highlights, and drawings to any PDF page
  • Fill out interactive form fields and add digital signatures
  • Insert, delete, or reorder pages within a PDF
  • Reduce PDF file size with lossless or quality‑adjusted options
  • Redact sensitive information permanently
  • Save edits directly back to the original file
  • Open multiple PDFs and drag files onto the thumbnail strip to insert them
  • Search text within the document and zoom smoothly
