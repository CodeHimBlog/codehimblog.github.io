About Yengi

Yengi provides a desktop IDE where developers can interact with AI models, have the system plan tasks, call tools, modify code, verify builds and automatically fix errors. It also includes specialised pipelines that generate 3D assets or Unity scripts directly inside the respective applications.

The program is built on .NET 10 LTS and runs only on Windows. It supports local LLMs such as Ollama, Qwen, DeepSeek as well as cloud APIs. The autonomous agent loop follows a Plan → Tool Call → Code Mutation → Verification → Auto‑Fix cycle, allowing the IDE to automatically edit files, run builds, and repair failures. For 3D work, Yengi offers a two‑stage pipeline that first creates a detailed blueprint and then generates Blender Python or Unity C# code, with optional real‑time viewport vision using multimodal models. The IDE includes a workspace with settings to enable or disable these features, and it can connect to image generation services with diagnostic tools for connection testing.

Key features

  • Integrates local and cloud AI models in one IDE
  • Autonomous agent loop that plans, executes tools, edits code and self‑heals
  • Live Blender and Unity copilots with two‑stage asset generation pipeline
  • Vision capability to analyse Blender viewport snapshots
  • Built on .NET 10 LTS for modern Windows environments
  • Diagnostic connection testing for image generation services
  • Supports multiple programming languages and build verification
  • Portable installer with optional settings for tool toggles

Frequently asked questions

Do I need an internet connection?

Only if you want to use cloud AI APIs; local models run offline.

Can I use Yengi without the 3D copilots?

Yes, the Blender and Unity features can be disabled in the settings.

Is the source code available?

Yes, the project is open source on GitHub under AGPL‑3.0.

What programming languages does Yengi support?

It works with any language you can edit in the IDE and can generate code for Blender (Python) and Unity (C#).
