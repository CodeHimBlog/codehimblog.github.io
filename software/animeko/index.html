About Animeko

Animeko provides a single place to find, follow and watch anime series. It connects to the Bangumi service for episode information and synchronises your watch progress across devices. The app aggregates video sources, including BitTorrent, Jellyfin, Emby and custom URLs, and supports online danmaku comments.

Animeko is written in Kotlin/Compose Multiplatform and runs on Windows as a portable ZIP. It lets users browse anime details from Bangumi, search by tags or schedule, and view community ratings. Watch progress is automatically saved to the cloud, so opening the app resumes where you left off. Multiple video sources are combined automatically, and the app can fetch subtitles and danmaku from various providers. Additional features include a notification centre, configurable proxy settings, and support for video enhancement on iOS. The software is free, open‑source and licensed under AGPL‑3.0.

Key features

  • Browse anime information and community ratings from Bangumi
  • Search by tags, schedule or new‑release lists
  • Cloud sync of watch progress across devices
  • Automatic selection of video sources, including BitTorrent, Jellyfin and custom URLs
  • Integrated danmaku (comment) streams from multiple providers
  • Subtitle support for ASS and SRT formats
  • Notification centre for messages, reports and security alerts
  • Proxy configuration for network environments
  • Portable ZIP distribution, no installation required

How to install Animeko

  1. Click the "Download Animeko" button on this page. Your browser saves ani-6.4.0-windows-x86_64.zip (304.3 MB), usually to your Downloads folder.
  2. Right-click the downloaded file, choose "Extract All", and pick a folder (for example Documents or Desktop).
  3. Open that folder and double-click the Animeko program file (.exe) to start it. Nothing is installed, so you can also run it from a USB drive.
  4. Sign in with your Bangumi account to enable cloud sync (optional).

Frequently asked questions

Do I need to create an account?

An account is only required for cloud sync with Bangumi; the app works without it.

Can I use Animeko offline?

Yes, you can download episodes for offline viewing.

Is there an installer?

No, the Windows version is provided as a portable ZIP that you extract and run.

Which video sources are supported?

The app aggregates sources like BitTorrent, Jellyfin, Emby, custom URLs and supports subtitles and danmaku.

Is the software safe to use?

It is open‑source under AGPL‑3.0, allowing anyone to review the code.
