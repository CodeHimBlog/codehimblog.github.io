About dsh-TUI

dsh‑TUI provides a graphical‑style overlay for the DeepSeek Harness AI chat system inside a terminal window. It shows a cute pixel‑whale logo, progress bars, and quick‑access panels so you can work with the AI without leaving the command line.

The program runs as a terminal UI that connects to DeepSeek Harness. It displays a header with an animated pixel whale, live work status, a thinking indicator, and a TPS gauge. A side panel shows a todo list that can be folded with Ctrl+Q. The interface includes split‑diff cards, compact status lines, and image handling that respects size limits. Settings are applied immediately and can be saved for future sessions. A four‑step first‑run wizard guides you through signing in, selecting a model, choosing language and theme, and configuring shortcuts. The wizard can be reopened later with the /setup command. The UI works with the latest DeepSeek Harness validation lines and falls back gracefully when features are unavailable.

Key features

  • Pixel‑whale animated header with three startup intros
  • Live status panels showing work progress and TPS gauge
  • Todo side panel with history that can be folded with Ctrl+Q
  • Split‑diff view for file changes with adaptable layout
  • First‑run wizard that configures account, model, language, theme and shortcuts

  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
