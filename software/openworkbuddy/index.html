About OpenWorkBuddy

OpenWorkBuddy lets you generate and edit common office documents such as presentations, spreadsheets and text files with AI. You provide a task description, choose a language model, and the program creates a file you can open and modify in PowerPoint, Word, Excel or any compatible editor.

The program is aimed at people who regularly create reports, presentations, tables and other documents and want to speed up the process with AI. It runs on Windows and can use cloud‑based or locally installed models. After installing, you register an account, configure the model service (provider, model name, API endpoint and key), and then enter a task. The AI generates the requested file, shows a preview, and saves it to disk where you can open it for further editing. You can also ask follow‑up questions to modify parts of the same file. The interface shows the execution steps, allowing you to see how the result was produced. The software is free for personal, educational and non‑commercial use; commercial use requires a separate license.

Key features

  • Generate PowerPoint, Word, Excel or HTML files from plain text prompts
  • Choose any cloud or local language model and configure API keys
  • Preview the created document and download it for further editing
  • Edit specific parts of an existing file with follow‑up prompts
  • View the AI execution process and model settings in the UI
  • Supports both installed and portable versions for Windows

How to install OpenWorkBuddy

  1. Click the "Download OpenWorkBuddy" button on this page. Your browser saves OpenWorkBuddy-0.20.1-win-setup.exe (245.1 MB), usually to your Downloads folder.
  2. Open the downloaded file and follow the setup steps. Windows may ask for permission to make changes; click Yes.
  3. When setup finishes, start OpenWorkBuddy from the Start menu or the desktop shortcut.
  4. Prefer not to install anything? Download the portable version from the download table above, extract it and run the program from that folder.
  5. On first launch, register an account or sign in
  6. Open Settings → Model to select a service, enter model details and test the connection
