About Hudo

Hudo lets Windows users set up a complete development stack with a single command. It downloads and installs dozens of popular programming tools, configures environment variables, and can export or import the whole setup for easy migration to another machine.

Hudo is a command‑line bootstrapper designed for developers who want to get a ready‑to‑code environment on Windows quickly. With one command it can install 26 common tools such as Git, Node.js, Rust, Go, Java JDK, Python, MySQL, VS Code and many others. The installer runs in the user profile, adds the installed binaries to the PATH and does not require administrator privileges. If a download fails, Hudo automatically falls back to Chinese mirrors for faster access. After installation it configures each tool – for example it sets Git’s autocrlf, creates Maven and Gradle mirror settings, and initializes Conda. Hudo also supports exporting the current setup to a TOML file and importing it on another computer, allowing a complete development environment to be reproduced with a single command. The interactive menu lets users pick which tools to install, and a non‑interactive mode is available for scripting. All configuration is stored in a simple TOML file in the user’s home directory.

Key features

  • Installs 26 popular development tools with one command
  • Works without administrator rights, installing to the user profile
  • Automatically switches to fast domestic mirrors if the main source fails
  • Configures each tool (PATH, environment variables, mirrors) after installation
  • Provides an interactive menu and a non‑interactive mode for scripting
  • Can export the current setup to a file and import it on another machine for instant migration
  • Updates installed tools individually or all at once with a single command

Frequently asked questions

Is Hudo free to use?

Yes, Hudo is open‑source and free.

Is it safe to run on my computer?

Hudo only downloads official releases of the listed tools and runs without administrator rights, so it does not modify system files.

How do I update Hudo or the tools it installed?

Run "hudo update" to get the latest Hudo version and "hudo upgrade" to upgrade the installed tools.

How can I remove Hudo and the tools it installed?

Use "hudo uninstall " for individual tools, and delete the "%USERPROFILE%\.hudo" folder to remove Hudo itself.

Do I need an internet connection?

Yes, Hudo downloads the selected tools from the internet during installation.
