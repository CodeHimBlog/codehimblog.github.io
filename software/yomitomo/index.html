About Yomitomo

Yomitomo provides a single workspace for reading and annotating web pages, e‑books and PDF files. It stores your highlights, notes and AI conversations locally, so you can organise your reading material, ask questions and retrieve information without needing an internet connection, unless you choose to use an AI service.

The app runs as an Electron desktop program. You can drag and drop web URLs, EPUB, AZW3, MOBI or PDF files to add them to your library. Within the reader you can adjust font size, change the layout width, search the full text, and navigate using the arrow keys. Highlights can be recoloured, annotated and organised into discussion threads. By mentioning @assistant you can ask a connected large‑language‑model to add thoughts, explain passages or answer questions, and the assistant’s replies link back to the source text. All reading content, notes and AI API keys stay on your device; only anonymous usage metrics are sent once a day and can be disabled. The interface is available in Chinese, English and Japanese and supports light, dark or system themes. You can back up or restore the entire database, including original e‑books and PDFs, from the settings menu.

Key features

  • Import web articles, EPUB/AZW3/MOBI e‑books and PDF files into a single library
  • Highlight text, add notes, create discussion threads and publish distillations as Markdown
  • Ask AI assistants for explanations or to add thoughts by mentioning @assistant
  • Search across all highlights, notes and AI responses with a local embedding model
  • Adjust reading layout, font size and theme; use bilingual translation for articles and e‑books
  • Sync notes and reading statistics with WeRead after entering an API key
  • Back up or restore the whole reading database, including original files
  • View reading statistics and trends locally

Frequently asked questions

Is Yomitomo free to use?

Yes, it is open‑source and free.

Is the program safe for my privacy?

All reading content, notes and AI keys are stored locally; only anonymous usage data is sent optionally.

How do I get updates?

The app can check for updates from the official download page.

How do I uninstall Yomitomo?

Remove the program through Windows' standard Add or Remove Programs feature.

Do I need an internet connection?

Only when you want to use an AI assistant or sync with WeRead; otherwise the app works offline.
