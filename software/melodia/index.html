About Melodia

Melodia is a desktop music player that runs on Windows. It is designed to be quick to start, use little memory, and provide a clean interface for listening to local files, internet radio, and online lyrics.

Melodia plays audio files with bit‑perfect output and supports gapless playback, cross‑fade, and a 10‑band equalizer. It can read ReplayGain tags and even calculate ReplayGain for files without tags. The player shows timed lyrics from .lrc files, embedded tags, or an optional online lookup, and can display them in many scripts. Users can browse internet radio stations from a built‑in directory or add their own stream URLs. The library scans folders in parallel, watches for changes, and offers full‑text search, smart playlists, and tag editing that writes changes back to the files. A responsive mini‑player appears when the window is shrunk. Integration includes scrobbling to Last.fm and ListenBrainz, Discord Rich Presence, and media control support in the operating system. The UI is provided by Slint, keeping the memory footprint low, and the program is available in sixteen languages without needing a restart.

Key features

  • Bit‑perfect audio output
  • Gapless playback with cross‑fade and 10‑band equalizer
  • ReplayGain support and automatic calculation
  • Timed lyrics from .lrc files, tags, or online lookup
  • Internet radio directory and custom stream URLs
  • Parallel library scanning, live folder watching, full‑text search
  • Smart playlists and in‑app tag editing
  • Responsive mini‑player UI
  • Scrobbling to Last.fm and ListenBrainz, Discord Rich Presence, OS media controls
  • Sixteen language options without restart

Frequently asked questions

Can I use Melodia to play music from my local collection?

Yes, you add folders containing your audio files and the library will scan and play them.

Does Melodia support internet radio?

Yes, it includes a built‑in directory of stations and lets you add custom stream URLs.

Is there a portable version that doesn’t need installation?

The official releases provide MSI installers; a portable ZIP is not currently offered.

Will my music files be modified?

Tag editing writes changes back to the files only if you choose to edit them in the app.

Does Melodia work on other operating systems?

It is also available for Linux, but this listing covers the Windows version only.
