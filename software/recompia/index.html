About Recompia

Recompia lets you play the fan‑made Pokémon Pokopia game on Windows. It provides a native Windows version of the Switch 2 title and adds online co‑op, community mods and other enhancements.

The project recompiles the original Pokopia game so it runs directly on Windows without needing an emulator. Once the files are in place, the Recompia launcher starts the game, applies optional mods, and lets you connect with other players over the internet. The software is open source, free and includes a Discord community for support and discussion.

Key features

  • Runs the Pokopia game natively on Windows
  • Supports online co‑op play where each player uses their own character
  • Includes a built‑in mod browser to install community mods
  • Provides a launcher that can update the game files automatically
  • Shows community achievements and leaderboards
  • Allows you to adjust game settings such as graphics and difficulty
