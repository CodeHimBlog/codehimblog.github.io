What the labels mean

  • SupportedThe current release works on this Windows version.
  • Older version onlyOnly an older release works on this Windows version. Older releases may lack security fixes.
  • Runs, not supportedThe software runs, but the project does not support this Windows version.
  • Not supportedThe current release does not work on this Windows version.

How we check compatibility

Every listing shows the Windows versions that its current release works on, and we update it whenever a new version comes out.

Windows 7 and 8.1 no longer receive security updates from Microsoft. If you still use them, prefer software that is actively maintained and keep your data backed up.

Spotted an outdated status? Let us know.
