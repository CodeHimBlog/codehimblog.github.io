What the labels mean

  • SupportedThe project’s official website, download page or release notes state support for the current release.
  • Older version onlyOnly an older release supports this Windows version. Older releases may lack security fixes.
  • Runs, not supportedThe project says the software runs, but it does not provide support for this Windows version.
  • Not supportedThe project states that this Windows version is not supported.
  • Reported, not yet verifiedSupport is reported by a secondary source and has not yet been checked against official sources.
  • Not confirmedWe have not found reliable information for this Windows version.

How we check compatibility

We do not test every application on every Windows version. Instead, we record what each project’s official website, download page or release notes say about the current release.

Third-party download sites often list Windows versions that a project no longer supports, so we do not treat them as evidence.

Windows 7 and 8.1 no longer receive regular security updates from Microsoft. If you still use them, prefer software that is actively supported and keep your data backed up.
